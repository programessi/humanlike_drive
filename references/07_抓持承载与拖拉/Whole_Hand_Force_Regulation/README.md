# Real-Time Force Regulation for Whole-Hand Dexterous Grasping

[原文](paper.pdf) · [arXiv](https://arxiv.org/abs/2609.30082) · [项目](https://sangminkim-99.github.io/reactive-grasp-whole-hand/)

所读版本：v1，2026-09-24。调研日期：2026-10-26。重点核对§III接触估计、QP、驱动一致性与§IV实验及限制；已访问项目页，没有复现。

## 方法

通过连续跟踪的物体6D位姿、物体网格和手部关节反馈，利用SDF估计整个手表面的候选接触，不要求对应位置安装触觉。每周期更新接触位置、法向、抓握矩阵和接触Jacobian，再解QP分配力，约束摩擦、最小挤压力、驱动力矩及驱动一致性。

驱动一致性限制接触力在受控关节无法感知/主动实现方向上的分量。论文明确说这是保守分配限制，不保证物理接触必然实现目标力。输出通过接触Jacobian转换为手指力矩。系统另有反应式接近与失抓恢复。

## 证据与边界

有27自由度臂手实物的人工扰动演示，触觉不参与控制。仿真定量实验去掉重力；QP最小化净接触wrench并维持挤压，**没有显式估计和补偿重力、惯性或外部wrench**。需要物体连续位姿跟踪和几何模型，不能等同于仅凭关节位置闭环。

## 对方向盘的取用

已知轮盘几何适合尝试全手候选接触估计，并用承载响应验证。六驱动mimic手尤其需要按真实驱动空间构造有效Jacobian；不能给不可独立控制的指节任意分配力。可以先作为仿真诊断或抓姿筛选工具，不必立即替换当前PPO执行层。
