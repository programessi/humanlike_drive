# A Learning-based Controller for Multi-Contact Grasps on Unknown Objects with a Dexterous Hand

[原文](paper.pdf) · [DOI](https://doi.org/10.1109/IROS58592.2024.10801894)

Dominik Winkelbauer、Rudolph Triebel、Berthold Bäuml，IROS 2024。原文来自本地Zotero；2026-10-26核对方法、§V实验与限制，没有复现。

## 方法

根据粗略物体模型、关节状态与实测关节力矩，先估计外部力/力矩，再预测抵抗该外载所需的手指控制，转换为关节级阻抗控制器的位置目标。支持掌部与多个指节接触的power grasp，不局限指尖抓握。

解析弹性接触模型生成监督训练数据，两个网络分别学习外载估计与力矩预测；**不是PPO**。强调以较小总关节力矩抵抗外载，并保持摩擦裕度。外载估计存在不可辨识方向，因此采用偏好最小可解释外载的训练目标。

## 实验

仿真240个抓握、30个未见物体，每个抓握100种外载。普通抓握施加10N、精细抓握5N，4秒增载后保持4秒；偏离初始位置超过3cm或姿态超过20°算失败。83.1%抓握稳定是该仿真协议结果。DLR-Hand II有真实展示，控制运行40Hz，单次网络计算约6ms。

## 对方向盘的取用与限制

借用动态外载测试、固定闭合/自适应分配对照和能耗—稳定性比较。DLR手有逐关节力矩测量；Inspire电流/负载能否支持相同估计尚需标定。掌部接触与奇异位形可能令部分外载不可观，不能认为历史或网络总能恢复完整wrench。
