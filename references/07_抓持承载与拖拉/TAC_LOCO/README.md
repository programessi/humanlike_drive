# TAC-LOCO: Unified Whole-Body Control for Quadrupedal TACtile-Informed LOCO-Manipulation

[原文](paper.pdf) · [arXiv](https://arxiv.org/abs/2607.10132)

所读版本：v2，2026-07-15。调研日期：2026-10-26。重点核对§3、§4.3、仿真实验、限制及附录奖励/观测；没有复现实验。按预印本版本记录。

## 任务与方法

从已建立物体接触开始，Unitree Go2加WidowX机械臂和带触觉的夹爪，在运动中拉动物体，应对未知渐变外力与突然卸载。共享网络融合本体、历史和触觉阵列latent，联合输出运动及夹持动作。

抓握奖励分成三项：抑制过大夹持力、抑制物体—末端相对滑动、避免相对位移过大导致掉落。这使“夹得越紧越好”变成稳定性与负载之间的取舍。论文摘要报告47%抓握力降低及低于1%的掉落率；这些是作者特定协议结果，不能当作无触觉Inspire的预期收益。

## 对方向盘的取用

优先借用渐增负载、负载转移、突然卸载和换向测试。接管不只是另一只手接触：一侧要在负载增加时保持，另一侧要在卸载后避免继续积累挤压或运动。

## 限制

使用触觉夹爪，既不是五指手，也不是无触觉策略。初始抓取不在范围内。论文指出触觉归一化后适合识别相对变化，不保证绝对力阈值；真实机械臂带宽与力矩能力也有限。相对速度/位移惩罚不能未经修改全程施加到方向盘的换位手，否则会压制释放与重抓。
