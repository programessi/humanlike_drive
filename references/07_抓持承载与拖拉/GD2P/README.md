## “拉”不一定需要完整抓握

该工作研究桌面非抓持推拉：通过多指接触姿态，为物体提供稳定支撑或钩拉作用。先接触引导采样、物理筛选有效姿态，再训练物体几何条件的diffusion生成模型；测试时通过运动规划、可行性检查与排序执行。不是逐时刻联合腕手RL。

真实使用Allegro和LEAP手，包含朝机器人方向拉动桌面物体。物体由桌面支持，不能把成功推拉理解为能够悬空抗任意外载。项目页也指出近碰撞和物体倾覆等限制。

## 对方向盘的取用

提示可以比较包络握持、掌垫摩擦驱动和局部钩挂等接触模式，先物理验证再筛选初态。但轮盘接管时需要停止保持、抗回正和双向施力，单向有效钩拉不代表反向也可靠。

几何已知时，可借其物理筛选方法，不必先训练大规模diffusion。它的主要贡献在可行接触姿态和动作生成，不能替代闭环承载与自主换手策略。
