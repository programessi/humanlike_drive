## 与无触觉六驱动手相关的细节

Valkyrie配PSYONIC Ability六驱动手。根据抓握构型识别偏高、偏低、偏远等符号状态，选择小幅腕部平移修正，直到模型认为抓握已就绪。需要每个工具的一次可靠参考抓姿与带标签训练数据。

虽然题名包含tactile servoing，最终逻辑回归模型的特征是手指关节相对参考构型的距离乘积：食指×小指、中指×小指。不能仅据题名说它必须读取触觉阵列。也不能把参考构型差直接等价为握力；论文模型只是在特定数据上学习关联。

## 不掉落与抗拉是两种成功

共42次试验，7种工具各6次：工具从套筒取出后不掉落为in-hand grasp；人工不能在不反驱手指的条件下拉出工具为manipulation grasp。整体成功率分别0.98和0.60；五种硬件适配工具子集分别0.97和0.73。人工拉拽没有标准化力值，不是最大承载力测量。

## 对方向盘的取用与限制

可研究用主动关节位置、目标误差和历史预测接管就绪状态，以受控承载测试验证标签。不能只凭闭合程度或再接触宣称新手已承载。该工作有人工参考和状态标签，没有证明无示范RL、连续拖拉或双手换握；3cm腕部调整步长也不应直接用于当前轮辋。
