# Humanoid Rickshaw Pulling: Whole-Body Locomotion under Coupled Wheeled Loads

[原文](paper.pdf) · [arXiv](https://arxiv.org/abs/2610.04238)

Yangzhi Yang、Xiansheng Lin、Zhaoming Xie、Xiaobin Xiong。所读版本：v2，2026-10-07。调研日期：2026-10-26。重点核对系统、动作观测、教师学生、奖励、硬件及未来工作；按预印本记录，不推断会议接收。

## 真正的持续牵引，但手部被简化

Unitree G1通过定制6061铝合金末端与被动双轮车持续连接。策略以50Hz输出29维腿、腰和臂关节动作；**夹爪PD使用固定闭合目标**，没有学习手指调节。

教师读取车辆状态、交互力和负载属性；动作与隐变量蒸馏给读取本体历史的学生，再PPO微调。学生输入包含机器人本体、命令、上一动作和夹爪速度，不直接读取车辆状态、接触力及负载参数。奖励包括车辆速度/转向、平衡、机器人—车辆相对构型、夹爪—把手距离和执行代价。

实物验证起步、持续牵引、转弯与停止，包括总质量最高115kg的载人车。质量包含车辆与乘客，轮子承重，不能将该值解读为手可托举的重量或夹持能力标定。

## 对方向盘的取用

它提供从机械臂/全身出发的清晰对照：先固定末端夹持，学习持续负载下的运动和历史适应。机器人与被操作物的相对构型需要进入训练/评价，不能只看外部目标误差。

## 限制

没有证明抓握建立、抓握恢复或交替换手；这些被列为未来工作。定制末端与固定闭合条件不能当作六驱动Inspire自适应包络握持的证据。当前上身固定的方向盘任务没有必要复现其步态和全身网络。
