# HANDFUL: Sequential Grasp-Conditioned Dexterous Manipulation with Resource Awareness

[原文](paper.pdf) · [arXiv](https://arxiv.org/abs/2604.25126) · [项目](https://handful-dex.github.io/) · [项目所链代码](https://github.com/handful-dex/HANDFUL)

所读版本：v2，2026-07-07。调研日期：2026-10-26。核对方法、课程、真实部署和任务定义，并访问项目页；没有复现。

## 资源分配比第一步抓稳更重要

任务是先抓住一个物体，再用剩余手指推、按、拉抽屉、转旋钮或抓第二个物体，同时保留第一次抓握。利用active/inactive手指奖励，学习不同抓握模式；从第一阶段策略终态训练第二阶段，并按后续任务表现筛选抓握与策略。实现使用SAC，启发主要在任务和状态课程，不在更换RL算法。

## 真实证据边界

真实LEAP实验没有直接闭环部署仿真RL。作者收集成功仿真轨迹，用观测到的初始物体位置检索匹配轨迹，再执行所选轨迹。不能把视频解释为已经验证纯RL在线适应真实接触。

## 对方向盘的取用

把“留出手指资源”扩展为手指、腕姿和双臂关节余量：初始抓握不应耗尽后续旋转和接管所需自由度。这个扩展是待实验验证的设计推断。可借用从有效终态初始化下一技能、按下游表现筛选初态的方法。

## 限制

单手操作两个对象与双手作用于同一刚性轮盘不同。不是持续承载转移或方向盘角度跟踪方案，不能照搬固定active/inactive角色。
