## 我的理解

联动与驱动模型错误会直接破坏接触技能；更好的机械建模、标定和ADR是互补手段。

## 对当前方向盘任务的借鉴

检查Inspire的mimic是否符合真实联动与受阻运动；先验证命令响应，再决定是否需要腱/回差等更复杂模型。

## 限制与区别

定制魔方、状态估计和训练资源投入很大。URDF存在mimic不代表接触受阻后的实物响应已经建模正确。

## 建议怎么读

先读§4.1、§5与附录D.1；重点看旧/新联动模型差异及ADR边界推进；对照实物状态估计系统。

## 此前阅读记录中的方法与实验细节

[魔方论文](https://arxiv.org/abs/1910.07113)，本次读取全文§4.1、§5、附录D.1。

- 作者发现原模型中联动关节运动与实物不同；加入非驱动空间腱/滑轮，并校准相同命令下的响应。
- 附录D.1的简化魔方任务、每策略10次实物试验中，旧仿真训练策略平均完成4.8次面旋转；新联动模型加标定为14.3次。是联合改进的比较，不能分解为某单一参数的因果贡献。
- ADR从标定的初始模型开始，按边界测试表现扩大分布；不是免去机制建模。

对Inspire的启发：URDF线性mimic的正确存在只是起点。还需要实测驱动反馈映射、联动运动、接触受阻后的响应、死区和双向回差。是否需要更复杂联动模型，应由数据决定。
