## 我的理解

将仿真教师转成真实可执行的动作接口，再用人工在线纠正学习门控残差，明确承认有些gap需要真实数据。

## 对当前方向盘任务的借鉴

若位置接口或接触响应难以建模，可将少量真实纠正作为后备迁移路线；优先核对学生动作是否真机可执行。

## 限制与区别

包含点云、真实纠正数据及真实控制系统，不是纯仿真零样本迁移。当前尚未具备合格教师，不宜先增加纠正网络。

## 建议怎么读

先看教师与学生动作重标记；再看在线纠正数据和门控；最后看五类受控gap与真实系统配置。

## 此前阅读记录中的方法与实验细节

#### 4. TRANSIC：控制器差异难以完全模拟时，学习真实纠正

[论文](https://arxiv.org/abs/2405.10315)，[官方项目](https://transic-robot.github.io/)，[代码](https://github.com/transic-robot/transic)。本次读取v1 HTML全文及官方项目，未审计或运行代码。

- PPO教师使用特权状态和OSC便于探索；学生用点云和关节位置动作。教师轨迹中的实际关节位置用于重新标记学生动作。
- 这避免部署继续依赖不匹配的高层控制器；仍需实物关节位置控制响应合理。
- 人监控实机、必要时遥操作纠正；用纠正前后状态差训练残差，并训练门控决定何时应用。
- 五类人为加大的gap包含感知、控制不准确、形态、动力学和资产差异；它们是受控实验，不应直接当成所有实物部署误差的统计。
- 部署系统还有软夹爪、支撑墙、标定相机和1000Hz底层控制。

对当前任务的启发：若真实接触或执行响应难以准确模拟，可以考虑仿真基础策略加真实纠正适配。但这是后续候选，不是现在增加另一层网络的理由，也不是本次已实施的方案。
