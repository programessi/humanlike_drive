## 我的理解

迁移依赖标定、执行误差随机化、记忆策略和有效初态的组合；仿真接触无需逐点复制，但状态必须落在训练覆盖范围。

## 对当前方向盘任务的借鉴

先用真实命令—响应数据约束手模型，再围绕合理参数随机化；训练覆盖闭合量、延迟、回差和初始接触差异。

## 限制与区别

它是已放在手中的物体重定向，有真实状态估计条件，不是任意初态抓取。不能把其成功归因于单一PPO或随机化开关。

## 此前阅读记录中的方法与实验细节

[Dactyl论文](https://arxiv.org/abs/1808.00177)，本次读取v5全文，重点§3、§6、附录B/C。

- 记录实物手指动作与关节反馈，在仿真重放相同命令，优化阻尼、摩擦、刚度、限位、驱动力、增益和回差等参数；随机化以合理标定值为中心。
- 额外建模动作延迟、时间抖动、执行回差，避免把直接关节驱动当成真实腱驱动。
- 在其实物状态感知消融中，完整随机化连续完成目标的中位数为13；无随机化为0。该统计仅对应论文自己的任务与试验，不是方向盘预期结果。
- 初始化由物理过程生成并筛选，不是任意指定接触点；不代表部署时可从任意未抓取状态开始。
