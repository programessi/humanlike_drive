## 我的理解

感知更新频率、动作延迟和执行器响应也是物理闭环的一部分，不能只随机化质量与摩擦。

## 对当前方向盘任务的借鉴

在部署频率下训练和评估；考虑反馈不同步、命令延迟与驱动力限制；单独验证长时间保持。

## 此前阅读记录中的方法与实验细节

#### 2. DeXtreme：部署感知和时序也是物理闭环的一部分

[论文](https://arxiv.org/abs/2210.13702)，读取2024修订全文§2、§3、§5。

- 腕固定的Allegro，物体先放掌心；三台相机的外参标定到掌坐标系。
- ADR覆盖手的刚度、阻尼、限位、驱动力、物体物理参数、动作及观测误差和延迟。
- 策略在仿真30Hz；视觉估计虽可20Hz，部署固定15Hz，使物体观测每两个控制步更新一次。不是只追求推理越快越好。
- 论文仍指出视觉误差、实物故障和模型差异；重放实物状态时甚至出现几何穿透。
- 大规模训练结果不可按相同耗时直接映射到当前单环境工作站训练。
