## 我的理解

当前接触稳定并不代表下一步仍能转动。它以人类示范形成的可操作性先验指导旋转，强调接触配置对未来运动的影响。

## 对当前方向盘任务的借鉴

将“重抓后是否恢复关节余量、能否继续承担目标方向转动”作为指标；不能只统计重新接触次数。

## 限制与区别

方法使用人类视觉/触觉示范和能量先验。我们可借目标设计，但现有无示范、无触觉条件不能直接复制整套方法。

## 建议怎么读

先看manipulability的定义和先验训练数据；再看它如何引导残差RL；最后检查换握相关消融和真实传感条件。
