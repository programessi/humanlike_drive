## 任务边界

- 双臂 14 个主动关节，双手 12 个驱动；从动指节仍由物理联动约束执行。
- 20 Hz 策略、500 Hz 物理作为起点，底层力矩受限。
- 参考按外部时间推进，不等待实际轮角到达；预览 0–1 秒，每 0.1 秒一个点。
- 累计轮角及跟踪误差不按整圈取模；几何周期信息单独用 sin/cos。
- 已知轮轴位姿和轮盘几何，有连续轮角与本体反馈；无触觉 actor。
- 仿真接触力等仅用于 critic、奖励、诊断。需独立审计 actor 信息边界。
- 实际场景轮轴行程先审计，禁止通过提高目标范围越过物理止挡。
- 使用[固定机械零位的回正负载](WHEEL_LOAD.md)，每个物理步计算，与参考角和接触状态无关。

## 观测与动作

| 观测 | 维数 |
| --- | ---: |
| 臂位置、速度、目标误差 | 42 |
| 手驱动位置、速度、目标误差 | 36 |
| 腕部相对位置、6D 朝向、线角速度 | 30 |
| 上周期实际采用的动作 | 26 |
| 累计轮角、角速度、sin/cos | 4 |
| 11 个参考角度误差、当前参考角速度 | 12 |
| 轮辋半径、截面半径 | 2 |
| 合计 | 152 |

动作顺序：左右臂各 7 维，然后左右手各 6 维。臂输出受限速度并积分为目标，手输出驱动位置目标并限速；原始采样动作与执行后动作分别记录。目标积分状态必须可观测，并处理限幅后的积分累积。

M1执行起点：臂目标速度不超过0.6 rad/s，目标相对更新时测量值领先不超过5°，手目标速度不超过每秒有效半行程。臂保留2°边界，手按联动推导有效限位后各端保留0.01 rad；物理输出继续服从场景力矩上限。这些是仿真设置，不是硬件额定参数。

## 已实现网络

```text
状态与几何 140 → 256 → 128 → GRU128 ─┐
参考 12       → 64  → 64 ────────────┴→ 192 → 256 → 128 → 26
critic: 152 + 20 个特权量 → 512 → 256 → 128 → 1
```

ELU激活；actor使用tanh Gaussian，部署用确定性均值。已实现actor 258,740参数、critic 252,929参数，不额外加入在线归一化层。GRU、分支和宽度是候选配置，尚未验证最优性。

设计来源：Grasp2Twist 的统一臂手与非对称 PPO；SimToolReal 的目标条件臂手策略及历史；HORA/DexCtrl 的本体与命令历史；Inspire 工具操作的六驱动动作边界。未来角度预览与当前维度组合针对本任务设计。[论文库](../../references/README.md)。

## 历史训练实现

现有代码采用非对称 recurrent PPO，不让特权信息流入 actor；actor/GRU 联合更新，不预设换手调度器。已执行试训未通过可靠双向跟踪；单手学习、接管和大角度课程未完成。

`configs/stage_a.yaml`保存候选超参数；`configs/m2_smoke.yaml`给出当前可运行的4环境工程试训设置，入口为`unified_steering.train`。时序rollout、终止与时间截断bootstrap、GRU重置、tanh概率计算及恢复均有专门检查。不得把旧152维教师接口或旧24维checkpoint当作本接口兼容模型。
