# 方向盘回正负载

这是当前操作研究的等效物理负载，不是完整的轮胎、转向助力或车速相关模型。配置见 `configs/s00.yaml`，后续策略使用相同模型接口。

## 定义

固定机械零位为 θ₀，θ 为累计轮角（rad），不按整圈取模：

```text
τ_center = −τ_max · tanh(k · (θ−θ₀) / τ_max)
τ_applied = τ_center + τ_disturbance
```

弹簧小角度近似 `−k(θ−θ₀)`，大角度平滑趋于有限回正力矩。当前 k=0.3 Nm/rad、τ_max=1 Nm、θ₀=0°。例如偏角90°时约−0.439 Nm，360°时约−0.955 Nm。限幅仅针对弹簧项，不限制另外施加的扰动力矩或物理阻尼。

黏性阻尼和干摩擦沿用 MuJoCo 关节物理：b=0.15 Nm·s/rad、摩擦力矩0.03 Nm。Python 不再重复添加阻尼或用 sign 近似静摩擦；native joint stiffness 必须为零，防止重复计算弹簧。

每个500 Hz物理步根据实际角度计算回正项，包含初态准备过程。它不读取参考轨迹、抓握或接触标签，不依赖左右手是否释放；实际角度变化时力矩才相应变化。使用固定机械零位，不在 reset 时把当前角度设为新零位。

## 验证

```bash
# 在项目根目录运行；路径由脚本切换到本项目。
bash unified_steering/scripts/run.sh -m unittest discover -s tests -v
bash unified_steering/scripts/run.sh -m unified_steering.audit wheel-check \
  --output outputs/s00_centering_free_v1
bash unified_steering/scripts/run.sh -m unified_steering.audit run \
  --output outputs/s00_centering_hold_v1
```

已有输出目录不覆盖，重复运行请换新目录。

单元检查覆盖跨整圈回正、固定零位、有限力矩、势能与力矩一致性、无接触轮轴的能量衰减。全场景探测禁用手轮接触，在 reset 时设置±90°、±360°初始轮角，然后完全由物理积分自由运动5秒；另做关闭弹簧的90°对照。这验证负载不依赖接触，不代表机器人学会松手。

CSV 中 `*_applied_nm` 是上一物理步积分前实际写入的外部力矩；`*_state_nm` 是记录状态下计算的负载。二者可能有一个物理步的差异。干摩擦由求解器计算，不用一个简单状态公式冒充实际摩擦反力。

## 对后续训练与验收的影响

- 偏角保持必须对抗回正负载，目标角不改变回正零位。
- 松手和重新抓握期间回正项继续存在，回退算入跟踪误差。
- 当前静摩擦与刚度组合，在零位附近约5.7°以内可能停止回正；允许残余偏角，不宣称自由轮轴精确回到0°。
- 因此单手保持验收不能只在接近零位进行，应增加±15°、±30°等有明显回正负载的有效初态，再逐步扩大。
- 历史 S00 配置缺少 `wheel_load` 时弹簧关闭，以保留旧实验重现；当前诊断与候选训练配置已显式开启。
- 刚度、阻尼、摩擦和限幅均为仿真起始值，后续实测标定。随机化时保持回正刚度非负、阻尼非负，并记录参数。
