## 调用与时间

```python
from unified_steering.env import SteeringEnv

env = SteeringEnv()
obs, info = env.reset(seed=7, options={"support": "both"})
# 后续训练时替换为policy(obs["actor"], hidden_state)。
action = env.hold_action()
obs, reward, terminated, truncated, info = env.step(action)
```

策略周期50 ms，正常推进25个2 ms物理步。每个物理步更新关节目标、施加回正负载、检查接触/限位/输出；危险时提前结束。`info.physics_steps`及`elapsed_seconds`记录实际推进量。结束后必须reset。

默认回合10秒，参考为当前实测轮角起始的±5°往返，包含起始/端点/结束保持。参考按时间推进，无到达等待；五次多项式按10°/s速度、30°/s²加速度上限确定段长。预览当前及未来0.1…1.0秒。`reset(options={"angles_rad": [...]})`可提供绝对累计角目标；`set_reference([...])`在当前时刻开始一条新轨迹，调用者需要自己保证与上一条轨迹连续。全部目标限制在±400°；物理轮盘±450°，任务在±440°终止。

## 动作26维

顺序见`contract.MOTOR_NAMES`：左臂7、右臂7、左手6、右手6。

- 前14维为归一化臂关节速度，范围[-1,1]，对应±0.6 rad/s。每控制周期先做`0.6×上周期实际速度+0.4×本次指令`滤波，再每物理步积分目标。
- 目标与当步实测臂角之差限制在±5°，目标离原生臂限位保留2°，同时限制每个物理步的目标变化。三者无可行交集时终止，不通过跳变目标规避限速。5°是更新目标时的边界，随后物理积分仍会产生跟踪误差，二者分别报告。
- 后12维是归一化绝对驱动位置；按机械联动推导有效区间，再各端预留0.01 rad。手目标速度≤每秒有效全行程的一半。两侧拇指俯仰有效区间为[0,0.5] rad，执行区间为[0.01,0.49] rad。
- 裁剪后实际臂目标速度回写滤波状态，防止累积；上周期实际动作放入观测。原始输入与执行后输出分别记录，未来PPO计算概率必须使用原始采样动作。
- `hold_action()`保留当前手目标、臂速度为零。**26维全零会改变手目标，不是保持指令。**

所有执行器保持场景中的有限输出；重力/偏置补偿通过位置PD控制输入实现，仍经过执行器力矩上限。执行器不读取轮角、参考或接触标签，不运行IK或圆周轨迹控制。无运行时换手调度器，离轮臂可自由接受动作。

## 观测与量纲

返回Gym Dict：`actor`为float32的152维，`critic`为float32的172维。字段顺序见`contract.OBSERVATION_FIELDS`。

| 字段 | 缩放 |
| --- | --- |
| 臂/手主动关节角 | 按联动后的有效区间中点及半行程归一化 |
| 臂角速度 | 除0.6 rad/s |
| 手角速度 | 除每秒半个有效行程 |
| 臂目标误差 | 除5° |
| 手目标误差 | 除有效全行程 |
| 腕部位置、线速度 | 固定轮轴坐标系，分别除0.3 m、0.3 m/s |
| 腕部姿态、角速度 | 旋转矩阵前两列依次拼接；角速度除1 rad/s |
| 上周期执行动作 | 归一化后的26维 |
| 轮角、轮速、周期信息 | 累计角/π、角速度/(20°/s)、sin、cos |
| 11点参考误差、参考角速度 | 累计误差/π、速度/(20°/s) |
| 轮辋/截面半径 | 已冻结几何0.14/0.3、0.014/0.05 |

累计角和误差不裁剪、不取模；0°和360°可区分。Gym观测空间使用无限边界是有意的，不把归一化误认为[-1,1]保证。

腕部FK与Jacobian在单独的传感器数据对象中计算，只复制主动臂q/dq。Actor没有读取被动指节真值、接触力或碰撞结果。当前M1没有观测噪声，critic前152维与actor相同。额外20维为：左右手作用在轮盘中心的固定轮轴系合力/合力矩12维（力/20 N、力矩/1 Nm），回正外力矩1维、轮盘摩擦1维、轴阻尼1维、轴干摩擦1维、臂/手增益倍率2维、动作/观测延迟2维。M1增益倍率恒1、延迟恒0，没有实现动态随机化。

## 初态与边界

`reset`直接载入有校验和的物理快照，恢复qpos/qvel/act/warmstart和原有抓握目标，清除准备外力及仿真时间。没有每次reset的在线IK或轮角夹具。10个单手初态来自S00-B的+30°及离轮臂±2°关节扰动，新增1个双手初态经S00有限PD离线准备。名义回正配置与S00相同。`support`可以是both/left/right/mixed，`state_index`可固定初态。mixed均匀抽取11个快照；初态分布不代表大范围状态覆盖。

离轮手停放范围只决定初态，不在任务过程中锁手。初始已抓握，不训练抓取建立。环境没有奖励“始终双手接触”或规定换手时间。

## 奖励与终止

每步奖励按实际推进秒数积分，各项与加权贡献分别放入info，权重在YAML中修改：

| 项 | 默认权重 | 定义 |
| --- | ---: | --- |
| 轮角跟踪 | 2 | `1/(1+(误差/3°)²)` |
| 角速度跟踪 | 0.5 | `1/(1+(速度误差/(10°/s))²)` |
| 大误差 | -0.2 | `min(Huber(误差/15°),4)` |
| 臂限位余量 | -0.2 | 进入10°或10%行程的较小软边界时二次惩罚，各关节平均 |
| 其他物体间隙 | -0.1 | 现有启用几何距离低于3 cm时二次惩罚；正常手轮接触不计入 |
| 动作变化 | -0.02 | 相邻实际动作差/2的均方 |
| 臂动作幅度 | -0.005 | 实际归一化臂速度均方 |
| 真失败 | -20 | 仅失败时一次，不按dt缩放 |

这些是训练起始权重，尚未由学习结果验证。独立评价记录角度RMSE、峰值和执行层介入比例，不以奖励总分宣称任务成功。

真失败包括臂余量小于2°、原生关节超限超过0.02 rad、轮角到达440°、非正常接触力超过1 N、输出超上限、无可行目标、非有限状态或MuJoCo数值警告。0.02 rad仅是软关节约束的穿透容差，不扩大参考/目标限位。两手离轮或误差大本身不立即终止，给重新抓握留出机会。间隙在20 Hz计算，危险接触在500 Hz检查；碰撞覆盖仍取决于当前稀疏几何。

`terminated=True`不可bootstrap；时间到仅`truncated=True`，可以对最终观测bootstrap，但未来GAE不可穿过reset。数值失效返回最后一次有限观测并标记`observation_valid=False`，不修复物理状态继续运行；未来采集器需剔除该失效样本的异常输入。

## 复现

```bash
# 只在缺少新双手快照时执行；已存在时拒绝覆盖。
bash scripts/run.sh -m unified_steering.initialization
bash scripts/run.sh -m unittest discover -s tests -v
bash scripts/run.sh -m unified_steering.validate_env --output outputs/m1_environment_new_run
```

验证器包含11例保持回归、10,000步固定/小扰动/全范围随机动作及至少100次reset、4进程吞吐测试。探索动作允许触发安全终止；需报告原因，不能把其终止率当作学习策略的成功率。短stress回合5秒仅为增加reset覆盖，正常环境默认10秒。CPU吞吐含500 Hz检查及20 Hz几何查询，不等同于训练器或GPU物理吞吐。
