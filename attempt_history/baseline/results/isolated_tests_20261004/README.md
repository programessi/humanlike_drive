# 当前基线：脱离驾驶上游的操作测试结果

日期：2026-10-04。**34 组测试已全部执行并完成记录**，请求仿真时间 12620 s，实际执行 12327.44 s（约 3.42 小时）。其中 33 回合完成请求时长，1 回合因轮角越界提前终止。整个过程没有接入实时视觉、路径点或 CARLA，没有训练，没有修改控制策略、场景、IK 表或权重，也没有执行任何改进对策。

结论：**基线具备分钟级保持和部分连续操作能力；动态跟踪可靠性依赖轨迹与物理条件。PPO 在部分任务中明显有益，在另一些任务中会恶化结果。关掉 PPO 不能消除全部漂移，接触存在也不能证明握持对应关系稳定。**

## 3. 关键发现

### 3.1 长时间本身不是必然导致漂移的原因

中心保持 10 分钟时，两组后期误差均趋近于零。-15° 和 -30° 保持也能稳定较长时间。+15°、+30° 保持的 PPO 组有更多接触中断和残余波动，正负方向具有不对称性。

这说明“预抓握后待得越久就必然失败”不成立。**持续运动、反向、接触状态变化与策略工况更需要关注。** 不同任务的短时误差也不统一：±15° 慢正弦 PPO 前 8 s 已有 5.67° RMSE，驾驶回放 PPO 前 8 s 为 2.11°；不能把某一个短回合低误差推广为所有短回合都低。

### 3.2 小转角、慢速度并不总是对当前 PPO 更容易

±15°、0.02 Hz 的 PPO 组，第一分钟 RMSE 8.93°，随后上升到约 20°并形成持续偏差；零残差组全程仅 0.304°。PPO 条件下仍有 94.6% 双手同时接触，所以单纯“有接触”的奖励/指标不能区分良好跟踪与有偏抓握。

这一轨迹的积分在 **99.3%** 控制步上达到 ±0.2 rad 限幅，主要为负限幅。PPO guard 在 **97.0%** 控制步上已降低残差，平均残差缩放仅 0.101。不能解释为“PPO 在整个 10 分钟都持续全强度输出错误动作”。启用 PPO 的系统在早期走向了不同状态，后续回退未恢复原有低误差轨迹；究竟是哪些腕部/手指残差引起这种接触变化，还未被本次测试分离。

当前策略训练的正弦频率为 0.10 Hz，本次 0.02 Hz 慢正弦检验的是不同工况。因此不能仅依据快正弦或训练回合表现认定它已学习普适的角度跟踪。

### 3.3 PPO 也确实改善了部分连续任务

停留反向序列中，PPO 2.787°，零残差 12.550°；零残差后段出现较大偏差，而 PPO 逐分钟误差多数维持在约 2–3°。±30° 慢正弦中 PPO 避免了对照出现的轮角越界。快正弦中 PPO 的全程平均误差也略低。

**结果支持保留 RL 作为候选，但需要重新审视它改善了哪些工况、破坏了哪些工况。** 不能据此直接决定一律关掉 PPO，或认为重新训练一定能解决底层问题。

### 3.4 驾驶回放确认了操作层自身的长期偏差

同一条 300 s 驾驶目标序列、不接实时驾驶上游：

| 分段 | PPO RMSE | 零残差 RMSE |
|---|---:|---:|
| 前 200 s | 0.609° | 2.085° |
| 后 100 s | 14.779° | 16.735° |
| 最后 60 s | 17.358° | 19.235° |

PPO 组后 100 s 积分全部处于限幅，但至少一手接触比例为 **100%**。随着偏差增大，掌部绕轴角与轮角的相对关系也明显改变。它支持握持滑移、接触重排或运动学对应关系改变的解释，但掌部角是代理量，不是指腹滑移直接测量。

这说明实时视觉或 CARLA 反馈并不是此次漂移的必要条件，操作层在固定输入下就能复现。它也说明普通角度积分不能持续修复这种状态变化。该回放没有耗尽 ±0.95 rad 手部参考范围：PPO 最大参考约 39.83°，零残差约 40.94°；本次不能把误差直接归因于参考角到达工作空间边界。

### 3.5 关节参考与接触负载仍需独立评价

多个 ±30°、反向或驾驶回放条件，名义 IK 关节参考变化速度峰值达到 **15.13 rad/s**，即使手部参考弧角已限速 0.6 rad/s。这与之前 IK 表的局部解变化和关节插值问题一致；本次只记录，没有修复。它是实际动态测试中被触发的参考速度问题，尚不能证明它独自导致了某次漂移。

全套 500 Hz 采样的最大单接触力为 **170.92 N**，非手部轮盘接触力最大值为 **0 N**。低频采样可能漏峰：±15° 慢正弦零残差组，50 Hz 峰值为 83.1 N，500 Hz 为 139.9 N。

这些是仿真模型里的受力，不是实机安全认证。现有内部自碰撞过滤、未标定接触参数和手部力模长指标仍限制对真实损坏风险的判断。

## 5. 核验完成情况

1. 原环境与只读观察器在同样 100 步动作下：qpos、qvel、观测、奖励最大差为 0。
2. 17 个配对条件：初态信息、物理参数及共同执行时段的处理后目标全部一致。
3. 两组 nominal 驾驶回放的 3000 个 10 Hz 轮角，与旧 `servo_replay` 记录最大差为 **0 rad**；本次 50 Hz 与旧 10 Hz RMSE 的微小差异属于采样差异。
4. 两个禁用轮盘接触的对照：轮盘保持静止，接触力为 0。正常测试无轮盘执行器，无外力或直接广义力写入。
5. 全部原始记录的时间间隔、样本数、角度误差公式与有限数值已核验。基线场景、IK 表、策略权重及三个控制源码的 SHA-256 测试前后一致。

## 6. 对策建议：尚未执行

建议优先级依据本次结果和之前的 IK 检查，而不是承诺某项改动一定有效：

1. **先检查并约束名义参考。** 处理 IK 解连续性和末端几何误差，对关节速度/加速度单独限幅；圆弧角限速不能替代这些限制。修复后用相同序列做配对测试。
2. **把稳定抓握作为独立目标。** 研究能在现有 Inspire 上观测的负载、位置与滑移代理，区分“碰到了”与“稳定包络”；对受约束方向研究顺应控制与双臂受力协调。原始手负载不能直接等同于当前仿真接触力。
3. **定位残差作用后再改策略。** 分析早期臂部与手部残差如何改变接触，比较工况条件化残差/回退。当前 guard 不能恢复已改变的握持状态；不能仅调大积分去追长期偏差。
4. **扩展训练与长回合验证。** 后续加入慢速、快慢变化、停留、反向和多分钟持续操作，明确稳定接触/滑移目标，使用真机可获取的 actor 输入。历史或记忆模型可以作为对照，但不能代替几何修复。
5. **稳定跟踪之后再做换握。** 若相对握持关系持续漂移，需要显式卸载、释放、重新建立抓握；当前策略不具备这种恢复机制。换握与拟人性应另设任务，之后再接驾驶上游。
