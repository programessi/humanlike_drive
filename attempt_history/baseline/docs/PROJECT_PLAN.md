# H1-2 操作方向盘驾驶 CARLA：仿真实施方案

更新：2026-10-03。本文区分本机已检查事实、建议方案和待实现功能。

## 目标与首版范围

最终闭环：CARLA 前视 RGB → 驾驶模块 → 目标方向盘角度 → H1-2 双臂与手控制 → 手与方向盘物理接触 → 方向盘实测角度 → CARLA 车辆。

首先实现固定躯干的 H1-2 操作仿真方向盘。双臂及手部参与控制，固定骨盆、躯干及腿部，不依赖站立平衡。座位、方向盘中心、倾角和机器人安装高度均可配置。首版纵向速度用独立控制器维持低速，踏板操作另列后续任务。

机器人操作模块可以读取关节、方向盘编码器及接触状态；最终驾驶模块使用 RGB、车速和可选导航指令。CARLA 的道路真值只用于调试基线、训练标注与评估，不能把使用真值的结果称为视觉驾驶。

## 已有任务与目标的差距

1. **转动成功不等于跟踪成功。** 当前主要判断转角是否越过阈值，并奖励转动速度。驾驶需要双向跟踪、停止保持、回正，必须以带符号的目标角度误差和角速度误差定义任务。
2. **固定根节点不等于固定躯干。** 当前右臂动作包含 `torso_joint`，需要按本项目安装条件锁住躯干，并重新求解双臂可达工作空间。
3. **演示类型不同。** `generate_h1_2_inspire_demo.py` 的 `static_wheel` 分支直接设置方向盘 qpos，是可视化演示；`generate_h1_2_steering_turn_only_demo.py` 通过关节动作推进环境，但使用预定动作序列，未按方向盘误差构成控制闭环。文件名中的 closed_loop 也不能代替代码与指标检查。
4. **手部动力学需审计。** 当前 ManiSkill 会每步投影 mimic 手指的 qpos/qvel；此处理可能改变接触能量。MuJoCo 原始模型有 51 个 motor，也不能把每个手指关节均视为实机独立可控，应依实际联动关系建立约束/传动模型。
5. **碰撞几何需重做。** G29 原 URDF 包含 `filenamse`、`bae_link.STL` 拼写问题。整只轮圈直接采用凸包碰撞还可能填满中间空洞；使用 CAD 外观、分段胶囊/凸分解碰撞更合适。
6. **受力指标需完善。** 当前把接触力向量求和后取模，双手相向夹紧时可能抵消。需额外记录每个接触的力、法向载荷总和、峰值及关于方向盘轴的力矩。
7. **模型参数未标定。** 既有 ManiSkill 轮圈半径默认 0.20 m，方向盘无限旋转，阻尼和摩擦是配置值；不应视为真实 G29 的尺寸、转角范围或力反馈。

## 技术选择

首版已采用 **MuJoCo + Python** 实现机器人接触控制，复用 H1-2 原始 MJCF，参考 G29 尺寸与 ManiSkill 分段轮圈/任务设计。接触 PPO 用 CPU 并行环境训练，视觉模型使用本机 GPU。

ManiSkill 保留为参考和后续批量强化学习候选，不同时维护两套新环境。GPU 已恢复可见；是否迁移应按实际训练吞吐决定。

CARLA 负责车辆、道路和相机；MuJoCo 负责机器人、手和方向盘，通过 Python 桥接。无需把机器人接触仿真塞入 CARLA。

## 分阶段实施与验收

### A. 模型和几何基线

- 组装固定躯干 H1-2、座位支架和被动方向盘，统一坐标系、关节名、角度单位与正方向。
- 锁定腿部和躯干；设置合理关节限位、执行器力矩/速度限制、手指联动与碰撞过滤。
- 用逆运动学验证左右手在轮圈上的接触点和手掌姿态；先从小角度范围开始，不预设双手固定握持能够覆盖整圈。
- 可视化可用时检查碰撞体；同时保存自碰撞、穿透、关节余量和可达性数据。

验收：模型能稳定保持初始姿态；双手预抓取位姿可达；轮圈空洞真实存在；移开双手时方向盘不受机器人动作影响。

### B. 接触转动与目标角度跟踪

先从预抓取状态开始，单手验证推/握轮圈的接触，再加入双手协同。将接近、闭合抓握、转动、保持、松开分为可检查的状态。

基线采用目标角度误差反馈 + 轮圈接触点轨迹 + 双臂 IK + 关节 PD/笛卡尔阻抗。给定轮心 c、轴向 a 和初始接触向量 r，参考接触位置为 `p_ref = c + R(a, theta_ref) r`，同时处理手掌姿态、关节限位和两臂之间的内力。跟踪过程根据实测转角和滑移调整参考，限制角速度、加速度和输出力矩。

方向盘没有追踪目标角度的隐藏电机；正常 rollout 不直接改机器人/方向盘 qpos 来制造转动。若加入回正力或模拟力反馈，要作为独立外部负载显式建模，并做无手接触对照。

建议首轮测试：0 → +15° → 0 → -15° → 0，逐步扩展至 ±30°、±60°；所有目标经过速度/加速度限制。再用低频正弦测试连续跟踪。更大转角需根据实测可达性设计松手、换手和重抓。

建议验收门槛：阶跃稳态误差 <3°，0.1 Hz、±30° 正弦跟踪 RMSE <5°，连续运行 60 s 无数值发散。正弦 RMSE 和单次 60 s 已达到，完整阶跃/安装偏移验收尚未完成。同时报告接触丢失、峰值接触力和执行器饱和率，不只看角度误差。

若确定性基线难以处理滑移/换手，再训练 residual RL 或模仿学习策略。RL 先使用关节和接触状态，目标为跟踪误差、动作平滑、滑移及过载控制；训练随机化摩擦、阻尼、延迟、轮心位置。视觉驾驶与精细接触控制分别建立基线。

### C. CARLA 联合仿真

- 安装/定位 CARLA 服务器与匹配版本 Python API，先验证低分辨率相机与同步模式。
- 实际配置：CARLA 10 Hz、机器人控制 50 Hz、接触积分 500 Hz，每个 CARLA tick 对应 5 个机器人控制步和 50 个积分子步。
- 固定执行顺序：读取当前驾驶目标 → MuJoCo 子步推进 → 读取轮轴实际角度 → 写入 CARLA 控制 → CARLA tick → 取得对应 frame 的相机数据。对齐仿真时间戳，不混用旧图像。
- 归一化转向使用 `steer = clip(sign * (theta_measured - theta_center) / theta_fullscale, -1, 1)`。`theta_fullscale` 是单侧满量程，按选定方向盘范围标定；同时核对 CARLA 车辆的转向曲线及速度影响。方向盘角度不是前轮转角。
- 初次使用 CARLA 道路真值生成目标角度，隔离机器人执行误差；只把该阶段称为集成测试。

验收：低速直道、缓弯与 S 弯中，CARLA 采用的 steer 可逐帧追溯到物理轮轴读数；保存横向偏差、压线/碰撞、速度、目标/实测方向盘角度和时序延迟。

### D. 视觉驾驶闭环

使用前视 RGB 提取车道/预测短程路径，再由路径控制器输出方向盘目标，车速控制器暂时独立。先做白天、固定天气、清晰车道、低速道路跟随。路口路线选择加入导航指令后单独评估。

已用 CARLA 教师采集并训练视觉模型。第一版 ResNet-18 全局池化 + 5 个横向路径点在 60 s 内成功，但长程出口弯失败；独立视觉对照也失败，说明不能只归因于机器人。正在升级为保留 2×4 空间特征的 ResNet-18 + 完整 5 个二维路径点，增加弯道采样权重。标签中的道路弧长不能直接当成车体前向坐标。

机器人侧增加可选的目标转速约束、目标角速度输入和 PPO 残差回退；纵向控制可根据视觉转向需求及实测轮盘滞后减速。这些机制不向视觉策略输入地图真值。

验收：相同道路上对比理想转向执行器与机器人执行器，分别量化感知误差、转角执行误差和闭环驾驶性能。

### E. 大转角和实机迁移

增加双手交替换握、连续跨越较大角度、力反馈扰动和恢复策略。随后将仿真方向盘编码器替换为实体 Logitech 输入、将机器人执行器接口替换为 H1-2 控制接口。实际部署前核对手型、轮径、安装几何、转角范围、关节约束与力反馈参数。

## 当前结论

已经实现驾驶室组合场景、固定坐姿 H1-2、被动轮盘、双臂 IK/PD 接触控制、Gym 环境、PPO 训练/恢复/评估、ResNet-18 路径模型与模仿学习、CARLA 数据采集和联合仿真接口。六项核心测试通过；无接触对照中轮盘保持静止。

PPO 已分三阶段试训，计数累计 802816 步。30°、0.1 Hz 正弦目标的 30 秒测试中，IK/PD 基线 RMSE 约 5.66°，连续跟踪 PPO 为 4.07°；峰值接触力从约 132.5 N 降至 87.8 N。随机化模型在 ±45°、摩擦/阻尼随机化的 60 秒单次测试中 RMSE 为 4.78°，没有提前失败。这些是限定任务的初步结果，不是全范围驾驶验收。

三种驾驶室视角和视频保存在 `outputs/`。CARLA 安装、教师联调和第一版视觉训练已完成；900° 总映射的 60 s 视觉闭环行驶 153 m、零碰撞/压线、平均水平横向偏差 0.169 m。长程评估未通过出口弯，不能称为不限路况的自动驾驶系统；改进版本的最终结果以 RESULTS.md 为准。大转角换手、完整从远处抓取和踏板操作尚未实现，首版内部自碰撞被过滤，实机迁移前需完善。
