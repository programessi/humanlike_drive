# H1可达性守卫与双手物理回归

2026-10-23。实现见[reachability.py](../../../src/wheel_manipulation/hand_only/reachability.py)，接口及限制见[HAND_ONLY.md](../../../docs/HAND_ONLY.md)，后续任务建议见[HAND_CENTRIC_DESIGN.md](../../../docs/HAND_CENTRIC_DESIGN.md)。

当前接口`inspire-dual-hand-wheel-v2-h1-reachability`：137维观测、24维动作。只含双手的物理仿真保留；独立影子H1模型在线检查完整双腕位姿与连续关节路径，不执行臂动力学，不提供参考轮角伺服或换手轨迹。这不是离线可达域查表。

## 守卫配置

- 关节限位余量5°，每关节最大步长`1rad/s × 策略周期`。
- IK拟合容差0.25mm、0.15°；接受后的目标采用关节解的精确FK位姿。
- 关节路径采样间隔最大0.005rad，8组既有肘/掌/躯干守卫间隙至少12mm。
- 雅可比姿态权重0.12m，最小奇异值阈值0.005。
- 失败后缩短候选步长；完全拒绝则保持上次接受目标。物理手掌实际位姿无法通过局部可达检查时终止回合。

八组稀疏守卫与离散采样没有覆盖所有机器人、手指、方向盘和驾驶室网格的连续碰撞；也未证明臂加速度、力矩、闭链内力或真实带宽可行。实际手掌检查为20Hz，不是500Hz物理硬约束。回正负载尚未实现。

复用原[physics_v1](../physics_v1/README.md)协议：固定名义初态，准备1.2秒，每组6秒。转动组前4秒按±2°/s给腕部脚本，后2秒停止。没有学习策略、轮角闭环控制或人工换手脚本。

## 边界测试

新增6项独立运动学边界：完整目标不变时冗余关节不漂移；不可达平移回滚；相同位置下不接受无法执行的姿态变化；接受动作满足关节步长和FK一致性；关节限位内的臂躯干碰撞仍被拒绝；实际浮动手掌越界可检测且不改变接受命令。

完整38项回归测试全部通过，用时22.337秒，日志见[tests.log](tests.log)。原有双手接触/执行边界仍保留。

## 结论与下一步

已引入实际H1几何和构型的运动学限制，同时保持双手接触物理执行。只证明名义小角度脚本可运行，以及明确的不可达/碰撞情况能被筛掉。没有训练新137维policy，没有证明自主接管、完整换手、大幅双向跟踪或sim2real。

后续应先加入回正负载并确认真正需要换握的连续可达范围；从有效初握、单手承载与邻近抓握恢复状态逐步训练集中式历史PPO，最终评估大范围双向协调。不得用任意固定角度触发松手代替学习换手时机。
