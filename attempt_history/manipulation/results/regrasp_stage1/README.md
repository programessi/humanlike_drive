- 独立场景恢复112组不同手指之间的碰撞；保留相邻结构/CAD重叠相关排除。腕部已移除原±6cm/40°箱子，保留径向/轴向、命令领先量与关节执行限制。这些稀疏约束不等于完整避碰或实物安全保证。
- 保留时间戳的正负对称参考，确定性限速/限加速度与0.5秒预览；不等待实际轮角到达后才推进时间。

## 物理可行性证据

[运动学与接触审计](feasibility_v1/audit.json)、[固定抓握扫描](feasibility_v1/fixed_grasp_scan.csv)：恢复指间碰撞后，名义准备仍形成双手接触；短时零动作没有报告机器人碰撞。固定握持到约55–65°时一侧局部IK残差增大，90°时位置残差约16mm，反向左右对称。这是局部优化扫描，不是全局不可达证明。

[低速物理诊断](physics_v1/summary.json)共15条14秒轨迹：双手/左手/右手主承载，各从0°、±20°、±40°物理准备开始，按预定腕速度+2/−2/+2°/s运动，没有轮角反馈伺服。

- 双手开环误差RMSE约0.595–0.730°；左手主承载约0.798–1.492°；右手主承载约0.764–0.936°。该误差相对于脚本积分目标，不等同于策略按时跟踪误差。
- 主承载单手的平均绝对轮轴接触转矩约0.031–0.033Nm；空闲手平均接触力范数之和约0.05–0.07N，仍有微小/间歇接触，不能声称严格零接触的单手验收。
- 全部完成14秒，当前机器人碰撞诊断峰值0N；没有证明完整释放/重抓路线、外载鲁棒性或RL自主协调。

随后[开手初态审计](free_hand_initialization_audit.json)发现：原6.5cm轴向退让仍有约1.86N手指接触，9cm仍约0.48N，12cm这次准备为0N。新的B/C默认采用12cm，后续还需对多准备状态验证；不能把原6.5cm初态当作严格单手状态。
