# 双手方向盘操作：暂时移除机械臂

2026-10-23，按用户要求，将当前问题简化成双手接触操作。独立实现位于 [`hand_only/`](../src/wheel_manipulation/hand_only/)，实际诊断见[实验记录](../results/hand_only/physics_v1/README.md)。原有机械臂任务及模型保留。

## 简化边界

场景中只保留左右Inspire手、固定轮轴与被动方向盘。两只手各有一个自由运动的掌部底座，各保留6个主动驱动、原始联动指节、惯量与碰撞形状。共12个手指位置执行器、12条关节联动等式约束、2个掌部free joint和1个被动轮轴。物理执行不含肩、肘、臂腕关节；另有不参与物理积分的H1运动学模型检查可达性。

这里保留手掌的平移与转动。大半径轮辋的包络转动需要手掌随接触位置移动；固定掌部仅靠手指转动会成为另一类受限指内操作任务，不能默认保持原来的角度范围。

## 动作及物理执行

仍为24维归一化动作，20Hz：

| 索引 | 输出 |
| --- | --- |
| 0–5 | 左掌切向/径向/轴向线速度，以及轮轴坐标系下的三维角速度 |
| 6–11 | 右掌同样的六维运动命令 |
| 12–17 | 左手六驱动的位置目标 |
| 18–23 | 右手六驱动的位置目标 |

手掌速度经过0.1秒滤波并积分成目标位姿。每轴线速度上限0.05m/s、角速度上限40°/s；目标位置领先实测不超过12mm，姿态领先不超过10°。径向范围0.085–0.28m，轴向范围−0.14–0.10m。它们是几何坐标与边界，执行器没有目标轮角反馈或自动跟随轮角的圆弧参考。

虚拟腕部以笛卡尔PD产生物理力和力矩：位置增益600N/m、阻尼30Ns/m，姿态增益8Nm/rad、阻尼0.35Nms/rad。包括重力补偿在内，每掌合力范数限制为30N、合力矩范数限制为2Nm。MuJoCo以500Hz积分实际动力学。执行器用前向雅可比读取实际速度，不解臂关节控制目标；独立的可达性守卫使用局部IK筛选命令。

手指沿用有限驱动力的位置执行器，Kp=1.5、Kd=0.06、每驱动总力矩上限0.35Nm；从动指节通过原等式约束运动。执行过程中不直接写入手掌、手指或方向盘的物理位置；直接状态设置仅用于reset。方向盘始终没有执行器。

这个执行器代表理想化的可移动腕部。可达性守卫增加运动学限制，仍未建模真实机械臂的带宽或负载能力。恢复双臂时，仍需检查同一腕部命令能否被真实执行层实现。

## H1可达性守卫

默认开启，代码在[reachability.py](../src/wheel_manipulation/hand_only/reachability.py)，最新[审计记录](../results/hand_only/reachability_v1/README.md)。这是在线局部运动学检查，不是已经生成的离线可达域地图。

每次从上次接受的14维关节构型继续求解候选双腕完整位姿；每关节步长不超过`1rad/s × dt`，距离关节限位至少5°。对候选关节路径按最大0.005rad间隔采样，检查现有8组肘/掌/躯干几何守卫，间隙至少12mm；加权雅可比最小奇异值不得低于0.005（姿态权重0.12m）。IK位置拟合容差0.25mm、姿态0.15°，实际腕部目标使用接受解的FK位姿。

完整候选不通过时依次尝试1/2、1/4、1/8、1/16步，仍不通过则保持上次接受目标；目标积分不继续堆积到被拒绝位置。双手作为一个组合检查，不允许各自可达却相互碰撞的已覆盖守卫组合。完整位姿不变时不进行冗余关节重排。当前没有臂加速度/力矩可行性证明，稀疏守卫和离散路径采样也不构成全模型连续碰撞保证。

每个策略周期另检查物理手掌的实际位姿；若顺应运动导致其离开可验证的局部可达域，则终止回合并记录`actual_wrist_outside_arm_envelope`，不会直接修改物理位置。该检查在20Hz执行，并未在每个500Hz物理子步加入真实机械臂约束。

可通过`HandOnlyConfig(reachability=ReachabilityConfig(enabled=False))`关闭守卫做消融。训练/评价必须记录该配置。恢复真机执行时，应让守卫构型与实际机械臂分支对齐；当前准备过程使用一次静态求解，既不规划接近抓取，也不提供换手轨迹。

## 观测

当前接口标识为`inspire-dual-hand-wheel-v2-h1-reachability`，单帧137维；旧122维双手接口和152维教师均不能直接加载到这个环境。

| 观测 | 维数 |

| 主动手指位置、速度、目标与实测之差 | 36 |
| 上一动作 | 24 |
| 双掌实际位置与6D朝向表示 | 18 |

| 归一化影子臂关节构型、上一命令接受比例 | 15 |
| 总计 | 137 |

不向actor提供接触力、驱动力矩或从动指节真值。新增影子臂构型用于描述守卫的冗余分支，防止执行限制成为隐藏状态；关闭守卫的消融中这15维为零。掌部状态在本实验中假定可观测，直接来自虚拟腕部；恢复双臂后应明确由关节反馈/FK或状态估计获得，并对齐守卫构型，不能据此宣称已经消除了实物观测gap。

## 当前任务与训练边界

先研究已建立抓握后的保持、±5°小角度转动、反向以及到位后的停止。参考仍由外部按时间给定并做确定性限速，不等待实际轮角到达后才推进；当前环境提供保持、正转、反转与往返参考。奖励接口包含轮角、轮速、至少一手接触、动作变化和保持段实际腕速惩罚，是待验证的初稿。

当前**没有为这个新接口训练PPO**。现有结果均为固定动作脚本的物理诊断，不是新policy的表现；也没有据此证明已经修复原策略的持续扭动。需要新训练并独立比较轮角精度、保持段实际腕/指运动、命令漂移和接触稳定性。

已增加臂构型限制，但当前小角度脚本没有触及边界，仍不能证明存在换手需求。还需验证真实需要重抓的命令范围、单手承载和附近有效抓握恢复。新的[双手任务设计](HAND_CENTRIC_DESIGN.md)将目标明确为回正负载下、不中断控制的双向跟踪；回正负载和相应课程尚未实现。

## 运行

从项目根目录执行，使用新的输出目录：

```bash
bash manipulation/scripts/run.sh -m wheel_manipulation.hand_only.scene

bash manipulation/scripts/run.sh scripts/audit_hand_only.py \
  --output results/hand_only/new_physics_audit

# 可选的脚本诊断视频，含SCRIPTED标注
MUJOCO_GL=osmesa LP_NUM_THREADS=1 bash manipulation/scripts/run.sh \
  scripts/audit_hand_only.py --video --output outputs/hand_only/new_script_audit
```

Gym环境入口为`HandOnlyEnv(HandOnlyConfig(...))`，`reset/step`返回标准Gymnasium接口。当前先完成环境和物理审计，没有启动新的长时间训练。
