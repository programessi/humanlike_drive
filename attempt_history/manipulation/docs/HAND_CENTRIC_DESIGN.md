# 以双手为中心的双向方向盘操作

2026-10-23，根据用户进一步明确的任务更新。本文件区分设计建议与已经完成的功能；不代表已训练出换手策略。

## 任务定义

上游给定带时间的目标轮角序列，确定性模块提供角度、角速度和短期预览。下游自主协调双腕与十二个手指驱动，跟踪正转、反转和停止命令。持续转动导致某手接近不利构型时，另一手先建立足够的控制，原手释放、重新定位、重抓；在此期间仍能抵抗回正负载。初始接近物体和视觉抓取不在本阶段范围内。

已知轮轴与轮辋几何，允许用几何坐标、接触区域先验和成熟运动学算法。它们不能提供按时间播放的双手运动轨迹、预设换手时刻或固定左右手角色。目标是学习接触与控制权的转移，而非再次学习上游速度规划。

模仿学习并非因为几何已知就没有价值；它可以提供有效动作先验。但当前不以人体演示为前提，先尝试纯仿真RL和初态课程，避免把示范采集变成必要条件。

## 系统分工

```text
带时间的角度命令 → 确定性限速/平滑 → 角度、角速度、预览
                                               ↓
本体与执行历史 → 集中式循环双手策略 → 双腕速度＋双手驱动位置目标
                                               ↓
                     H1运动学可达性守卫 → 有限阻抗执行 → 物理接触
```

双手是同一个策略的两个输出分支。左右角色由当前构型和命令决定，不使用两个互不知情的独立策略。掌部需要平移与转动，不能只训练固定腕部的手指运动。

先保留浮动双手物理模型隔离机械臂动力学，用H1运动学约束避免利用无限腕部自由度。再把同一个动作接口接回实际双臂执行层，检查位置误差、延迟、阻抗和可用负载，必要时继续适配。浮动腕部的30N/2Nm上限是实验参数，尚未证明真实H1在每个构型都能实现。

## 网络与训练建议

首选非对称循环PPO：部署actor从第一天只读取可取得的观测，critic使用仿真特权信息帮助训练。先不增加人工示范、diffusion或额外教师蒸馏链路。若直接训练的历史actor确实遇到部分可观测瓶颈，再比较HORA式特权隐变量教师与历史适配学生。

建议网络起点：左右手分别经共享权重的两层64维编码器，采用一致的局部坐标并显式保留左右标识；拼接双手特征和全局轮盘/命令特征，经128维GRU、256/128维MLP，输出24维高斯动作。GRU在回合开始时清零，训练序列先用16–32步（20Hz下0.8–1.6秒），需要正确处理循环状态和截断。critic用独立的256/256/128维MLP。规模是待消融的工程起点，不是文献已经证明最优的结构。

部署actor信息：

- 十二个主动手指驱动的位置、可获得的速度或差分、目标与实测误差。
- 双腕位置、朝向、速度、命令与实测误差；恢复双臂时来自关节反馈/FK和状态估计。
- 上一动作与交互历史，用于感知松紧、滞后、死区和未知负载的影响。
- 轮角、轮速、当前参考角/角速度、未来参考预览和已知几何。
- 执行分支的构型与可达性限制状态。当前守卫增加14维归一化影子关节位置和1维命令接受比例，防止相同腕姿态下不同冗余构型成为隐藏条件。接回双臂时必须与真实执行层的构型/参考对齐。

actor不要求触觉、仿真接触力、精确摩擦系数或从动指节真值。critic和训练奖励可读取接触、摩擦、负载及数值穿透等特权信息，这些不能渗入部署动作通路。历史反馈有助于推断接触，不等价于精确测得抓握力。

动作保持24维：每手切向/径向/轴向速度和三轴角速度，共12维；每手六个驱动位置目标，共12维。mimic从动关节由机构模型联动。策略不直接输出14个臂关节目标、不输出上游参考速度，也不需要一个先验的“换手”按钮。

## 必须补齐的任务物理与目标

1. **回正负载。** 当前环境只有轮轴阻尼/摩擦，需要加入可配置的中位回正力矩、阻尼和有限扰动；例如初始近似`tau = -k*theta - b*theta_dot + disturbance`。回正相对机械中位，目标轮角不进入负载模型。先用温和负载，再增加强度与随机化；这不是对真实汽车回正特性的完整建模。
2. **真实需要换手的可达域。** 用H1连续可达性与关节余量扫描确认哪些命令确实需要接触重排。参考必须进入该范围，并覆盖不同初始抓握配置；不人为规定转到30°就松手，也不因进入困难构型就立即结束正常换手探索。
3. **双向与停止。** 从早期就同时采样正负命令和停留，后期加入换手中途反向与不同时间尺度。旋转进度或单向角速度奖励不能替代按时间的角度跟踪。
4. **允许局部释放。** 不奖励两手永久贴在初始材料点。围绕至少一手有效握持设计任务，并容许另一手暂时离开轮辋。局部轮辋的包络指标可以辅助学习，不能把整个方向盘中心当作每只手的包络中心。
5. **稳定的目标执行。** 限制目标领先实测的幅度；命令被守卫截断后保留接受目标，防止持续积分造成windup。保持段评价实际腕/指运动，避免只靠轮角达标掩盖持续扭动。

奖励以角度和角速度跟踪、负载下保持为主；加入双手同时失去有效控制、反转回退、碰撞/穿透和接近执行极限的代价。只在保持段适当惩罚多余动作；对释放手施加过强的贴合、静止或动作惩罚会阻止换手。关节余量/可操作性用于引导恢复有用构型，不能鼓励无目的反复重抓。具体权重需通过消融验证。

“至少一手碰到轮盘”只是必要条件。必须检查在回正负载与扰动下能否控制轮角；仿真以接触和响应联合诊断。无触觉条件下不能仅凭闭合角度宣称实物握持已可靠建立。

## 课程与验收

| 课程 | 训练分布 | 必须验证 |
| --- | --- | --- |
| A 双手小角度控制 | 多个有效初握，正负小角度、停止、温和回正负载 | 角度/轮速精度、停止后实际腕指运动、接触与抗扰稳定 |
| B 单手承载与恢复 | 初始一手已承载、另一手松开或轻触，左右均采样 | 承载手控制轮角；自由手能建立可用新抓握 |
| C 一次完整换握 | 从接近不利构型的有效状态出发，目标要求继续转动 | 建立接管→释放→重新定位→重抓，全程保持控制，换握后恢复运动余量 |
| D 连续双向协调 | 从中位和多种配置出发，大幅转动、停留、反向、扰动 | 自主选择时机与角色、多次完整换握、换手途中反向、长时间角度跟踪 |

课程主要改变初始状态、目标分布和负载难度，不给逐帧手部轨迹或固定的换手时间标签。B/C可从经过物理筛选的中间状态训练，再要求D从普通初态自主到达这些状态。冻结评价集应包含未见初态、命令和物理参数，后续至少检查多个训练种子。

联合记录RMSE/峰值角度误差、正负方向偏差、保持段漂移、负载扰动后的回退量与恢复时间、完整换握成功率、双手同时失去有效接触的累计/最长时长、关节余量、命令截断、碰撞与穿透。接触断开时长应在物理子步统计，不能只看20Hz输出。具体角度、负载和时长门槛应在固定协议中预先给定。
