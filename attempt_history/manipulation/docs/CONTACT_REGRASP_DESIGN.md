# 双臂双手方向盘操作：论文精读后的技术方案

日期：2026-10-22。状态：**已进入独立实现、物理审计与教师训练，完整第一阶段未验收**。论文精读与下面的方法边界保留，实际运行结果以[第一阶段工作记录](../results/regrasp_stage1/README.md)为准。没有运行论文原代码或实物机器人；现有基线与模型保持原状。

## 1. 任务与当前状态

目标是：H1-2 上身固定，双 7-DoF 臂与双六驱动 Inspire 手统一执行给定的、带时间信息的方向盘角度参考。小角度时尽量维持自然双手握持；继续转动、当前抓握接近关节/碰撞/运动能力边界时，另一手接管，原手释放、重新布置并重抓；反向时根据当前构型重新协调。最终关心长时执行和实物迁移，而不是视频中短暂出现了转动。

上游路径点到目标轮角的规划，以及轮角参考的限速、限加速度、平滑和速度计算仍为确定性处理。策略学习的是**实现给定轮角运动的臂手动作**。腕部运动速度是控制动作，不能将其混淆为重新规划上游的方向盘期望速度。

实施本方案前，exploration 只做过单环境、单种子、24,576 策略步的保持/±3°试训，未通过稳定跟踪，未学会换手。它的 Actor 为140维，MLP→GRU→24维动作，仅critic有特权输入；旧奖励、±6cm/40°腕部箱子和35°终止范围仍保留在历史入口。新的`regrasp/`另行实现152维教师/历史学生结构、扩大释放空间并调整任务奖励，不能用旧实验结果代表新模型。场景文件中的机械范围不代表机器人已经能转到该角度。

### 两个会影响设计的实验细节

DexScrew §IV-E 的消融中，特权教师和历史学生优于“只给 critic 特权”的直接 PPO。这是本任务尝试教师/学生的依据，不是证明当前 PPO 失败一定由缺少教师导致。原文使用 8,192 个并行环境；正文称 1.5e9 步，表格列 3e9，不应精确承诺复现其预算。

DexScrew Table II 中，无触觉、有历史的真实数据 BC 螺丝刀进度为 87.50±18.61%，触觉加历史为 95.00±13.24%，直接 sim2real 为 41.60±26.21%。因此无触觉值得尝试，但不能把这些进度数字转述为纯仿真 RL 的实物成功率。DexCtrl §7 也明确承认本体历史的可观测性边界。

## 4. 总体结构与学习边界

推荐主线：**已知几何条件下的目标条件臂手策略；仿真特权 PPO 教师 → 无力感知的历史学生 → 必要时用特权 critic 做学生 PPO 微调。** 无需人类动作示范；学生蒸馏属于模仿仿真教师，不应笼统写成全流程只有 PPO。

```text
带时间的轮角序列 → 确定性平滑/限速/预览
                                  ↓
关节/轮角反馈 + 控制历史 → 历史编码器 → 集中式臂手 actor
                                               ↓
                              双腕运动12维 + 双手驱动12维
                                               ↓
                         几何坐标积分 + 联合IK/QP + 实际位置接口
                                               ↓
                                臂手与被动方向盘的物理交互
```

整套系统使用一个集中式 actor，同时决定左右腕运动和十二个手驱动目标。输出分成左右头只是便于尺度标定，不能拆成相互看不到状态的两个独立策略。每只七自由度臂剩余的运动学冗余由 QP 的关节边界、避碰和柔和姿态项处理；第一版 policy 不独立指定肘部冗余。如果证据表明这限制换手，再比较额外的肘部冗余输出，不先增加动作维数。

没有“目标90°就松左手”的部署状态机。开手、接管和重抓由连续动作产生。训练课程可以指定从左/右单手初态开始，但最终部署不输入左右承载标签或阶段编号。

### 4.1 动作：24维

每只手输出12维：

- 3维腕部平移运动，采用方向盘轴坐标中的**切向、径向、轴向**分量。
- 3维腕部旋转运动。
- 6维手驱动绝对位置目标，带驱动行程、速度、加速度与命令领先量限制。

双手共24维。手目标覆盖可用开合行程，不只是围绕原闭合姿态的小修正。所谓6维包含拇指等独立驱动，不把所有手指简化成一个闭合标量。

选择切/径/轴坐标是结构先验。对于腕部参考点，设绕轴的柱坐标为 `(rho, phi, z)`，策略切向速度为 `v_t`，则在机器人控制频率下积分：

```text
phi_next = phi + dt * v_t / rho
rho_next = rho + dt * v_r
z_next   = z   + dt * v_z
```

在远离轴心的有效腕部区域中使用该表示，并处理小半径奇异性；重新投影生成细分的笛卡尔参考，姿态用旋转指数映射积分。`rho` 是腕参考点到轴的距离，不强制等于轮缘半径。径向/轴向运动和腕姿态始终可调，所以可以离轮、避让和重抓。

**这提供了已知几何下的运动坐标，不提供目标轮角到腕运动的反馈控制律。** 不存在 `v_t = K*(theta_ref-theta)` 的隐式执行器；切向运动大小、方向、停止及双手配合仍由 policy 给出。研究表述应写清是结构化学习控制，不能宣称完全不利用圆弧几何。几何积分也不保证真实手指严格沿圆运动，物理接触与离散跟踪误差仍需评估。

### 4.2 部署观测：建议152维

在当前140维基础上，加上12维左右腕命令位姿相对实际位姿的误差，避免隐藏积分器状态完全依赖网络猜测。所有速度从带时间戳的位置差分、滤波得到；量纲归一化与左右符号单独标定。

| 观测 | 维数 | 实物来源 |
| --- | ---: | --- |
| 双臂14+双手12主动位置 | 26 | 编码器/实际驱动反馈，经标定映射 |
| 对应速度 | 26 | 反馈差分或经核实的速度接口 |
| 主动位置目标减实测值 | 26 | 已发出的、经执行限幅后的目标和反馈 |
| 上一步策略动作 | 24 | 软件记录 |
| 双腕相对轮轴位姿，平移3+旋转6，各一份 | 18 | 臂位置反馈的FK与轮轴标定；不使用从动指节真值 |
| 轮角与轮角速度 | 2 | 方向盘反馈及差分 |
| 当前至0.5秒、间隔0.1秒的轮角参考误差 | 6 | 上游参考，不是未来真实观测 |
| 当前参考角速度 | 1 | 确定性参考生成器 |
| 轮轴位姿与轮缘几何 | 11 | 标定：位置3、旋转6、轮径/轮缘厚度2 |
| 双腕命令相对实测的位姿误差 | 12 | 积分器记录与FK，各手平移3+旋转误差3 |
| **总计** | **152** | 不含触觉、模拟力矩、精确滑移或从动指节实测 |

轮角不在每回合随意重置为零，不用 `sin/cos` 丢掉多圈/机械限位信息。训练目标明确采用绝对标定角或一致定义的相对任务角；初始化误差与策略引起的漂移分别记录。

### 4.3 网络的初始具体配置

教师：特权信息 `p_t` 经 MLP(128,64) 编成16维 `z_T`；`[o_t,z_T]` 经 MLP(256,256,128) 输出24维动作分布。另用独立 MLP(512,256,128) critic 读取完整训练状态。教师与学生使用相同动作、相同命令平滑/延迟/限制接口。

学生：`o_t(152) → MLP(256,128) → GRU(128) → z_hat(16)`，再将 `[o_t,z_hat]` 输入与教师相同结构的动作网络，输出24维动作。GRU 隐状态在执行中保留，在任务真正重新初始化时清零。建议以2–4秒序列反传，处理约0.5–1.5秒的近期响应；这不是声称所有接触隐变量都能从这个时间窗精确恢复。

教师额外看到接触位置/状态、相对滑动、从动关节、执行器参数、轮轴阻力等训练信息。允许它使用这些信息简化探索，但对其依赖程度必须通过学生性能检验。`z_hat` 是为控制服务的隐表示，**不是牛顿单位的握力估计**。动作模仿为主，隐变量模仿为辅助，不要求网络精确重建不可辨识的逐点接触力。

第一版不引入 diffusion、VLM、大型 Transformer、离散换手分类器或可调增益输出。上述层宽、隐变量维度是可实现的起始配置，不是论文已经为本任务证明的最优解。保留当前直接 recurrent PPO 作为同任务、同接口对照，以验证蒸馏究竟是否有收益。

## 5. 先修物理任务，避免把问题误归因于网络

### 可达性与接触模型

先扫描当前机器人/轮盘位置下双手及单手抓握、释放、绕开另一臂、回到轮缘的可行构型与路径。不把某个固定角度当作人或机器人的换手阈值。用至少关节余量、碰撞间距、IK误差、单手可跟踪的轮角区间和扰动响应评价候选抓握。

原场景将同一手内的所有碰撞对排除，这对重抓任务过于宽松。应审核恢复必要的非相邻指间/拇指碰撞，仅保留 CAD 重叠或相邻刚性结构的合理排除。现有掌/肘/躯干几何约束也不等于完整驾驶室避碰。还需核对轮辐、手指碰撞几何与实际轮缘尺寸。

现有固定比例 mimic 是模型，不是已核实的欠驱动接触变形。应检查真实传动是否近似固定耦合，还是接触后会改变联动关系；随机化联动参数/柔顺性不能制造真实硬件没有的独立自由度。只改变摩擦而保留错误传动结构，无法可靠缩小 gap。

### 有效初始状态库

由开手、可达预抓握、缓慢闭合和物理稳定过程生成状态，而不是直接指定接触力或在执行中把手粘到轮上。覆盖双手握持、左单手、右单手、一手已离轮且接近新抓点、临近不利构型等状态。保存仿真状态可用于复位与课程，接触需重新计算并检查；最终完整评价过程中不得复位、搬动手或修改轮角。

静态看起来包住轮盘还不够。用限定速度的小幅双向轮角指令及受控外扰检查该状态能否真正传递转矩、停止和恢复。对固定轴方向盘，“不掉物体”没有判别力；没有手接触时轴摩擦也可能把角度停住。

## 6. 训练课程：同一策略逐步覆盖完整能力

课程进度由冻结验证集表现决定，保留先前任务混合，避免只训练新阶段造成遗忘。下表是课程拆分，不把A课通过称作完整第一阶段通过。

| 课程 | 任务分布与探索帮助 | 应学到什么 |
| --- | --- | --- |
| A：控制和停止 | 对称正负目标、保持/随机平滑序列；先±5–10°，再按可达范围扩大；小幅执行/初态误差 | 用腕手动作产生有方向的转动，反向，按时停止；保持不是单纯静摩擦停住 |
| B：接管准备 | 左/右单手物理初态等量采样；另一手在附近不同开合与接近姿态；保留双手任务 | 单手在规定负载下可控制，另一手可以建立有效新抓握；六个驱动和腕部始终都能行动 |
| C：一次完整换手 | 一手接近不利构型，另一手从可行重抓位置附近开始；后续目标要求越过当前固定抓握的可行区间；逐步扩大离轮距离和初态差异 | 新手有效接管→原手释放→原手避让并重抓→继续执行；双方向、双角色都练 |
| D：连续反向与长时 | 从正常双手状态出发，混合达到/越过换手需求的转动、随机停留、换手中反向与外扰；逐步扩大到几何验证可行的±60–90° | 在无阶段标签、无重置的连续序列中自主决定是否/何时换手，恢复可继续操作的构型 |

C课用近成功的物理初态和逐步回退的状态分布降低探索难度，不提供一个部署时必须遵守的固定时间表。允许训练早期使用短期的“重新建立有效抓握”奖励；该奖励按有意义的转移支付一次，不按松开/闭合次数持续支付，以防刷奖励。最终应靠持续控制能力和未来构型余量获得收益。

关键条件：大角度课程必须包含**当前固定抓握确实无法合格完成、存在可行换手路线**的目标；否则 policy 完全可能一直不松手。重抓工作空间与 QP 姿态约束必须允许这条路线，不能只改目标振幅而沿用±6cm/40°箱子。

### 教师到学生

1. 先用特权 PPO 教师完成A到C的关键能力与对照，逐步覆盖D。教师若都不会换手，不开展“迁移已经有希望”的结论。
2. 采用 DexScrew 式 DAgger：学生在随机化仿真中执行，教师对学生实际访问状态提供动作标签及辅助隐变量标签，逐步降低教师介入。只在教师成功轨迹上做离线 BC 容易漏掉学生偏离后的恢复。
3. 冻结学生单独验收。若存在可控的小幅性能损失，可用仅critic特权的 recurrent PPO 微调；该步骤仍不向学生 actor 输入力。
4. 若学生长期追不上教师，检查部分可观测性、教师是否依赖瞬时特权反馈、历史长度、动作多解与训练状态覆盖；不能只增加网络或无期限加训练步数。

“触觉未必需要”并不等于“任意接触状态一定能由本体恢复”。对不同接触状态但相似可见观测做配对测试，观察是否能用后续响应辨识。若真实输入确实不足，应先缩小准备/负载范围，或使用已验证的新测量通道。

### 训练规模与工程约束

先在 MuJoCo 保留已核对物理模型，测多环境吞吐和CPU/内存占用；可从单个训练作业内4–8个CPU环境起步，资源不允许则减小。PPO 起始可用256步rollout、clip 0.2、gamma 0.995、GAE 0.95；教师学习率从3e-4量级试起，按KL和有效动作幅度诊断。这些是起点，不是效果承诺。

几万步仅足以检查管线，不能与论文十亿级仿真数据比较；但短训失败也不能只归咎于样本少。先逐级检查“动作是否能接触并转动、奖励是否偏向不动、是否能从近成功状态完成重抓”，再给有效课程扩大预算。只有资源与瓶颈证据支持时才考虑GPU仿真迁移，届时必须重新验证联动/接触/执行接口。

## 7. 奖励与目标时序

核心目标由轮角/轮速跟踪、停止保持、可继续操作的构型余量构成，配合动作平滑、关节边界、碰撞与异常负载代价。训练时可使用仿真接触与载荷作为奖励/终止条件，不意味着部署时可观测这些量。

- 使用有明确尺度的角度与速度误差项，并保留到达后保持任务。速度奖励跟踪给定参考，不照搬“沿一个方向越转越快”的持续旋拧奖励。
- 早期局部腕姿态引导只作可衰减的辅助。最终奖励有效抓握集合与可继续运动的能力，不惩罚所有离开初始抓点的运动。
- 不永久奖励双手都有接触、不以接触点数或接触力越大越好。单点有力不等于可承载转矩。
- 不强制每段都换手、不奖励换手次数。小角度不松手与大角度及时重抓都应是高回报行为。
- 不能用很强的动作/姿态正则让“不动”比学习转动更划算；记录每项奖励与有效动作幅度，按性能推进约束。

参考序列保留时间戳。不等间隔路径点可以平滑后按控制周期重采样；轮角参考速度、加速度由确定性生成器算出。对外来序列先检查速度/加速度是否在声明的能力范围内，拒绝不可执行命令或明确记录参考重定时。

在本任务评价中，不能偷偷改成“实际转到当前点才发布下一个点”，也不能因为换手就冻结参考时钟；那测的是按事件到达，不是原来的时序跟踪。训练早期允许较慢参考和随机停留，但其时序必须预先给定并保存。

## 8. 缩小sim2real差距的具体顺序

1. **核实接口与单位。** 手驱动实际反馈、命令行程、控制率、延迟、限速/限力、控制模式；轮角零位/方向/范围；臂的真实位置执行接口。仿真也用对应的命令层，不把可读电流视为可写力矩。
2. **识别有效执行响应。** 用自由运动和保守接触条件下的命令/反馈记录估计速度、延迟、死区、饱和、回差/柔顺性。不能只以自由空间轨迹吻合作为接触模型正确的证据。当前仿真存在理想化PD/偏置补偿，需匹配真实控制链能提供的能力。
3. **随机化成对合理的状态分布。** 轮轴/轮径小偏差、抓握位置/腕姿、闭合量与准备时长、轮阻力/惯量、手轮摩擦、执行器响应/联动误差、噪声/延迟、有限外扰。范围从实测和几何可行性确定，不直接照搬论文很宽的摩擦区间。
4. **准备过程也进训练。** 仿真与实物都走接近、慢闭合、稳定/历史预热、微幅双向验证的过程。接触是过程结果；目标是落在经过验证的有效分布，而非力值一模一样。
5. **先限定迁移范围。** 从低速小角度开始验证学生，再逐步做单手接管与换手。真实数据若显示系统性偏差，用于更新执行器模型或有明确范围的适配；不承诺零真实校准即可直接迁移。

准备就绪指标应由可测量量定义：姿态/FK落在有效范围、驱动命令与反馈关系处于训练覆盖内、轮角/轮速满足稳定条件、微小双向命令能产生预期响应并停止。单看手指闭到某个数值不等于抓稳；目标—实测差也不能唯一解释成握力。仿真接触与外扰响应可验证这套可测判据的误判率，最终真实阈值须由真实测量确认。

如果以后确认PD可调，可把DexCtrl式增益头作为独立消融；若只能调位置/速度/厂商限力，模型必须使用这些实际接口，不能将其直接等同于PD刚度。

## 9. 第一阶段完整验收与边界

第一阶段完整目标仍包含：小角度双手保持、继续转动时一次有效接管/释放/重抓、反向重新协调。A课通过只代表基础能力，不能再称完成第一阶段。

下面是**建议的仿真验收目标**，不是已有结果或实物承诺；先通过几何可行性验证再确定最终角度与负载：

| 能力 | 测试与建议门槛 |
| --- | --- |
| 小角度闭环 | ±10°、正负阶跃/正弦/随机序列，参考速度先≤5°/s，常态RMSE目标≤1–2°；含保持与反向 |
| 单手能力 | 左/右单手分别完整执行，另一手确实无有效接触；在声明轮阻力/外扰范围内可跟踪并停止 |
| 一次有效换手 | 目标越过当前固定握持的可行区间；记录接管、释放、新抓点、继续控制、关节余量恢复；不是仅开闭一下手或擦过轮盘 |
| 换手误差 | 初期换手窗口峰值误差目标≤5°，常态与换手窗口分别统计，不用全段平均掩盖短暂失控 |
| 反向与连续运行 | 随机改变反向时机，包含换手中反向；先60秒，再300秒；无运行中复位/轮角强制赋值 |
| 泛化 | 独立准备状态、物理参数留出组合、至少3个训练种子；短换手测试可用100条独立场景，长时另设20条；报告成功率及置信区间 |

第一阶段几何目标可从可行的±60–90°探索，不保证恰好到90°才换手，也不宣称只要扩大到这个角度就自动学会。长期再扩大到±180°及硬件允许的更大范围。

换手成功的物理诊断要证明：接管手有实际控制能力、原手确实卸载并离开旧抓点、重抓发生在有后续操作价值的新构型；同时轮角持续合格。接触力之和只是辅助，应用单手对照、受控负载与接触产生的轮轴转矩验证。轮轴力矩/精确滑移可以只用于仿真诊断，不进入学生。

必须包含零动作、旧基线、同接口直接recurrent PPO、特权教师、历史学生，以及有/无有效初态课程、几何坐标动作与原笛卡尔动作的逐项对照。不要一次同时改所有组件再把收益归功于某篇论文。

最终“拟人”目前只能通过温和的关节/肘部/腕姿态偏好引导，不能声称无示范RL自然产生标准人类驾驶动作。遮挡也需先定义是双臂几何互挡还是实际相机/视野遮挡；本轮无视觉学生不证明主动视觉能力。真实安全不能由仿真中的单点峰值力、完成回合或稀疏QP约束保证。

## 10. 失败时的决策依据

- 教师不能跟踪/重抓：先查物理可行性、动作覆盖、任务奖励与探索，不称为sim2real失败。
- 教师成功而学生失败：重点查信息缺口、历史编码与DAgger分布，不把教师视频当作可部署能力。
- 学生名义场景成功、初态变化失败：准备分布和恢复能力不足，先收紧/扩充可验证分布。
- 仿真学生稳、实物差：重新检查执行器、传动、接触几何、延迟和轮负载差异；必要时有限真实数据适配。
- 纯RL教师在可行的近成功课程上仍长期没有进展：可以另做少量可行轨迹/示范引导的对照，但需明确方法已变更；不在没有证据时加入更多大模型。

这套路线的预期贡献是：在实际可用观测与执行接口下，学习带时间目标的双臂双手接触重排与跟踪，并验证对准备接触差异的鲁棒性。论文是否成立取决于上述能力与消融，不由使用PPO或引用主会论文决定。
