# 数据

| 位置 | 准备存放 |
| --- | --- |
| raw/human | 人类示范原始视频、姿态和手物交互记录，按采集会话归档 |
| raw/robot | 真实机器人状态、命令、示范、同步信号及人工干预 |
| raw/sim | 仿真策略轨迹、专家示范、纠正标签及失败记录 |
| processed | 经校验、转换和版本化的统一训练序列，格式待定 |
| manifests | 来源、字段/单位、接口、频率、校验和与处理来源清单 |
| splits | 轨迹/会话/种子级划分，以及留出集合的使用记录 |
| calibration | 机器人、手驱动、方向盘、坐标及延迟等标定记录 |

raw与processed的大体积内容默认忽略；manifests、splits和calibration中的小型记录可以纳入版本管理。原始数据保留时间戳；转换不覆盖原始文件。使用何种来源、字段和存储格式将在后续讨论确定。
