# 第一层物理协议：掌心摩擦驱动与上半圆操作

版本v1.4，2026-11-07。状态：仿真第一层当前代表范围已执行，完整±180°往返通过；结果和实际冻结条件见[验收报告](../../results/physical_feasibility/l1_v1/README.md)。对应[三层研究计划v4.2](../plans/RESEARCH_PLAN.md)。下文保留开跑前的候选方案；正式采用1°/s、0.1 N·m合成负载、40°短行程及接管前最多5秒有界等待。5°/s未通过瞬时掌力门槛，未做逐手整半圆动态通过声明；目标标定扰动通过有限电机执行，不再直接扰动受载qpos。360°／540°及实物尚未验收。[旧协议](TEN_TWO_FEASIBILITY_V1.md)及原结果保持历史含义。

## 1. 要回答的问题与当前路线

掌心施加径向预紧，随运动产生的切向摩擦能否成为主要转向驱动？手指通过现有驱动顺应、维持掌面稳定接触，是否能减少滑移和失接触？从9点／3点出发，双手各自在上半圆的哪些区间可以自然、受载地操纵，哪里受到拨片、轮辐、外壳、座舱或另一只手／前臂阻碍？

不追求四指逐一接触、深度包络或扣死拇指。若操作完成但主要依赖指部传力，保留为其他接触机制的证据，不计作本轮掌心摩擦主驱路线通过。

## 2. 固定物理条件与角度定义

- 保留坐姿驾驶室、原始关节、每手六驱动和URDF mimic；保留轮圈、拨片、轮辐、外壳及自碰撞，装配排除逐项记录。
- 校核实际掌面碰撞几何，区分掌心、手背和侧面；不以虚构凸起、增大摩擦或删除障碍掩盖贴合问题。
- 保留26维有限执行、原限位、限速、预紧上限及重力补偿边界。顺应通过已有驱动与有界反馈实现，不假定有侧摆或额外掌力执行器。优先调整整手位置、朝向和肩肘姿态，不逐指精修。
- 轮轴在任务中被动，仅受已声明负载；无角度伺服、直接设轮角或重置抓握。准备辅助如有使用，明确标注并在任务前移除、重新稳定。
- 旧90°初态与参考不自动继承。可复用通用工具，新初态、控制与评价独立版本。

**分开记录空间接触相位和累计轮角。** 从驾驶员视角定义上半圆为9→12→3及反向路径；轮轴倾斜时在轮盘自身平面内定义。记录掌面实际接触位置、轮圈材料位置及连续累计轮角，不能把空间上走过半圆直接当作轮盘已转180°。轮圈截面实际接触法向与盘面径向也分别记录。

## 3. 先补齐的诊断

按物理步记录接触位置、接触坐标系、作用到轮盘的力／接触力偶及几何对。接触局部力转世界系，明确作用双方符号，按真实轮轴计算：

`tau_axis = axis · ((contact_position - axis_origin) × force_on_wheel + contact_moment_on_wheel)`

分左右掌面、其他手部表面、拇指、四指和非轮圈部件汇总，分解法向与摩擦贡献；与广义接触力矩、轮轴动力学核对。理想径向压力本身几乎不提供轴向转矩，不能用法向力大小或接触点数证明掌心驱动。

滑移记录接触相对切向速度、累积位移和掌部相对轮圈材料位置的变化。微小滑移、接触点迁移、真正滑脱和主动释放分开。输出掌／指力矩、外负载、轮角误差、实际命令／输出、腕姿、关节余量、饱和与碰撞。零负载、反向过零与停转段单列，不能用净转矩接近零判断无人承载。

## 4. 执行顺序

### P0-A：9点／3点初态与上半圆路径筛查

1. 左手约9点、右手约3点，提出少量整手位置／朝向候选。轻握以维持掌面贴合，优先自然腕姿，允许起点小幅调整但须记录原因。若需改为其他起点，另列候选及调整依据。
2. 分别沿9→12→3及反向路径筛查每只手。先按15°空间相位采样，危险区加密；必要时改变轮盘材料角，检查轮辐／拨片随轮盘转动产生的障碍。
3. 记录整手和前臂姿态、关节余量、腕内扣角及前臂—手掌夹角、最小间隙、碰撞部位。另一手分别处于初态、释放退让状态，检查双手／双臂互挡和返回准备区路线。
4. 保存驾驶员视角、正面、侧面及接触近景，标明可行区间／受阻区间。若后续使用视觉观测，再单列相机可见性；本轮遮挡优先指真实机械干涉。

离线IK和摆角只用于筛查，不能作为动态成功。找不到自然初态或连续可用区间时，先报告限制，再调整整手／臂姿；不靠手指侧摆或过度腕折弯补偿。腕姿接受范围结合候选对比在动态验收前冻结，不把“未越限”等同于自然。

### P0-B：掌面贴合与非零负载保持

1. 经有限电机建立新初态；双手保持10秒，再分别左右单手保持10秒，另一手退离轮圈。
2. 对每只手施加双方向明确负载。候选恒定负载阶梯为0.05、0.10、0.20、0.40 N·m，从最低级开始，超出执行／接触边界即停，不要求全部通过。这是合成探索负载，不能称为实测G29。
3. 记录轮盘平面内径向预紧、实际表面法向力、掌面摩擦轴向力矩和指部贡献。保持阶段，以掌面摩擦有符号平均反负载力矩超过所需负载的一半作为初步主驱判据，同时核查各部位反向抵消和外负载平衡。
4. 动态主驱的初始评分方案：由轮轴动力学得到所需手部力矩，在非零负载且所需力矩符号稳定的片段，分别积分各部位力矩在所需方向的有符号贡献；掌面摩擦贡献超过所需手部力矩积分的一半，并核查指部反向抵消、力矩平衡及滑移。驱动、制动和反向片段分别报告，不以整条轨迹正反抵消后的比例评分。先验证分解与符号，再冻结该规则。
5. 冻结名义负载、轻握程度、允许滑移和腕姿范围。探索调参片段与冻结后验收片段分开。

不以无限增大预紧强行满足比例。接触可见但未独立承载，或主要由指部提供力矩，均不能计为本路线通过。

### P0-C：上半圆受载运动，优先推进0—180°

1. 从冻结初态出发，执行平滑 `0→±15°→保持→0→保持`，逐步到±30°、±60°、±90°、±120°、±150°、±180°。先取5°/s，目标和零位各保持3秒；负载与摩擦每批前固定。
2. 分别测试左手／右手在两个空间方向的实际可用区间，不默认镜像等价。主动手操作，另一手可卸载、释放或退让，不强制双手刚性跟随同一180°；记录空间路径与累计轮角。
3. 加入途中反向和跨零，例如 `0→+30→+15→−15→0` 及镜像，全程保留控制状态。较大角度的反向案例在通过范围内预先冻结。
4. 若单手可用区间不足以完成目标，先给出碰撞、腕姿、滑移、执行饱和等原因；需要时加入停稳接管，再尝试1°/s低速接管。先转移负载再释放，新手非零负载独立保持10秒并继续操纵；不固定180°才换手。
5. 输出每只手／方向的最大已验证跨度、上半圆接触轨迹和完整往返。未到180°如实报告边界，不能用离线姿态或拼接重置后的片段替代。

### P0-D：辅助作用、扰动与可选长轨迹

1. 对通过的局部窗口比较“掌面+自然轻握”和“掌面+较少手指支撑”。通过合法驱动调整，不移除手指碰撞；记录实际掌压／姿态差别，不冒称只改变一个变量。
2. 名义条件冻结后，测试两个单因素扰动和一个联合扰动，各5个固定种子／微扰初态；逐例报告，不作95%成功率结论。摩擦候选0.4、0.7、1.0，需记录MuJoCo组合规则与其余摩擦分量，不逐例调参。
3. 余力允许再采集更完整180°、360°、540°去程—保持—返回及重复接力；重点看新手继续操纵、旧手回准备区和下一次交接，无中途重置。长轨迹失败不撤销已成立的局部证据，也不冒称完整任务通过。
4. 原G29居中±450°不能验证±540°；进入该扩展前落实独立长行程模型／设备版本，不阻塞当前范围。

## 5. 工程门槛与阶段完成定义

以下为待验证目标。滑移、预紧／轻握、自然腕姿和动态主驱评分规则在P0-B之后、P0-C正式验收之前冻结；探索结果不充当独立验收。

| 项目 | 条件 |
| --- | --- |
| 动态完整性 | 已声明角度范围内完成去程、保持与返回，无任务中重置、轮轴辅助或扶持 |
| 精度 | 运动RMSE≤2°；各停止段末1秒峰值≤2°；10秒保持另报全段漂移 |
| 掌面接触 | 明确单手支撑的评分段，掌面有效接触占比≥95%，计数阈值先取0.05 N；另报最长失接触时间 |
| 手指辅助 | 不要求四指／拇指逐一接触；报告轻握改变对稳定性和滑移的影响 |
| 主驱机制 | 保持满足P0-B掌面摩擦反负载判据；动态按有负载、同向驱动／制动等片段分别核算力矩和功，排除过零段，冻结评分后再验收；不能只凭保持通过认定动态主驱 |
| 滑移 | 无脱离或无法恢复的持续滑移；速度、累积位移及最长失接触数值边界冻结后执行 |
| 执行与腕姿 | 原限位和有限输出有效，臂关节余量>2°；满足冻结腕姿范围，报告饱和与多视角，不用未越限替代自然性 |
| 干涉与碰撞 | 无自身／座舱非法碰撞；拨片、轮辐、外壳受力>0.05 N判失败；轮圈最大穿透<0.5 mm；另报路径最小间隙 |
| 接管（若用） | 先负载转移再释放，相对参考额外回退≤2°；新手完成独立保持及冻结跨度的继续操纵 |

**当前阶段交付：**9点／3点初态、逐手上半圆路径／干涉图、掌心摩擦传力证据、实际范围的完整受载往返。0—180°为优先目标；只达到部分范围就标部分完成，并列未解决约束。360°／540°及两次连续交接不设为当前必过项。报告分别给出“当前范围验证状态”和“最终T1—T4状态”。

## 6. 输出与后续专家数据

新运行存入 `outputs/physical_feasibility/<run_id>/`，报告存入 `results/physical_feasibility/`。保存场景与外部资产来源、实际初态、mimic、配置、源码／哈希、负载、物理步轨迹／接触、完整视频和失败片段。几何变更独立版本，旧结果不混算。

为成功轨迹同步保留带时间戳的观测、实际执行命令、反馈、底层控制器状态／内部目标、接触／接管事件和任务指令。保留物理步数据并记录控制频率；确认下游动作接口后再转换为对应频率的训练数据，不从qpos差分冒充动作标签。

这些是**仿真工程专家候选数据**，不是人类示范。通过合法性、动作可重放性和任务完整性检查后，按完整轨迹／会话划分开发与留出；失败或人工辅助另标，不直接混入成功BC。明确工程控制使用的特权反馈，避免下游部署观测泄漏。仅有局部数据时可支持同范围第二层研究，不能声称覆盖整圈或最终全任务。
