# P0试验协议：10点／2点避让拨片抓握的运动可行性

> 历史协议，已由[掌部主导P0协议](PALM_PRIMARY_P0.md)取代当前入口。下文原门槛与结果含义保留，不用于验收新主线。旧90°已[备份](../../results/archive/20261107_pre_palm_primary/README.md)。

版本：v1.3，2026-11-07。依据用户确认，本轮验收范围为**仿真P0**，实物接口与标定后续在[R0](../plans/R0_HARDWARE_CALIBRATION.md)单列；数值门槛不变。最新逐例结果、范围边界和视频见[仿真P0报告](../../results/p0_complete_20261107/README.md)。这是工程入口检查，不是论文最终方法对比。

对应[研究计划第2.3版](../plans/RESEARCH_PLAN_v2_3_before_palm_primary.md)。目标是回答：从当前10点／2点初态出发，怎样将人类的主导手控制、另一手释放／伴随和交替接管映射到机器人。最终任务包括±180°内双向连续追踪、360°和540°特殊操作；本协议先建立其物理入口，不能用P0通过代替三类行为完成。

## 1. 起点与环境

本轮起始抓握使用 `assets/scenes/p0_clear_grasp_v1.json`，参数为 `humanlike_drive/config/controller/p0_clear_grasp.json`。保持10点／2点抓点，采用更顺直的腕姿和远离拨片的手掌朝向；六驱动和URDF mimic不变。准备采用有限电机，8秒中仅前2.5秒有已标注轮轴居中辅助，随后5.5秒完全移除，再导出初态。配置来源与筛选见[决策记录](../decisions/2026-11-07_P0_CLEAR_GRASP.md)。

原 `basic_grasps.json` 中的1–4号预设仍可查看，其中原2号的静态5秒结果只属于原手型；撤销代码后遗留的 `results/ten_two_feasibility/` 不作为本轮证据。

每次运行保存实际使用的场景XML、抓握JSON、控制配置、mimic源、代码版本及SHA256。运动环境另记版本，不覆盖既有结果。

进入物理转向检查前完成：

1. 开启非相邻机器人部件自碰撞响应，记录相邻装配排除对，并重做初始抓握与保持。
2. 保留轮圈、拨片、轮辐及座舱碰撞；执行器保留真实限位和有限输出。
3. 定义轮轴外部负载接口，区分回正、摩擦、阻尼与任何准备阶段居中辅助。
4. 明确26维动作到实际目标的映射、目标限速和防预紧累积约束。显式控制与后续策略遵守同一执行边界。
5. 记录每步观测、命令、实际执行、轮角和接触；正式任务时轮轴不接受抓握辅助或角度伺服。

允许准备阶段使用已标注的辅助建立初态，但在任务起点前完全移除并重新稳定。手臂重力补偿单独记录，且与计划的实物能力对应。

## 2. 先检查离线可达性

检查以下模式：双手握持、右手握持／左手退开、左手握持／右手退开，以及接管时短暂双手接触。

从零位向左右候选角度扫描，先按5°间隔检查到180°，在约束接近边界处细化到1°。保存是否可达、关节余量、腕姿、手到拨片和机器人自身间隙。失败角度如实保留，不将左右结果默认对称。

轮盘摆角和IK只用于离线筛查。任何修改轮轴状态获得的姿态，均不能计作物理转向成功；随后必须通过有限执行器实际重放。

## 3. 按顺序运行物理案例

| 组别 | 操作 | 主要观察 |
| --- | --- | --- |
| A：初态回归 | 2号双手保持，再检查居中轮位单手释放；每项10秒 | 自碰撞开启后是否仍可保持，释放是否扫到拨片；此处不单独证明承载 |
| B：小角度往返 | 0→±30°、±60°、±90°→保持→0→保持 | 实际转动、打滑、腕姿、关节余量和返程 |
| C：主导手片段 | 在B组已验证轮位上加入明确非零负载，再分别测试两只手主导，另一只手退到可重抓位置 | 哪只手可以有效承载、何处开始受限 |
| D：停稳接管 | 在C组识别的可行区域内，新手接近、接触、承载，旧手释放 | 可行抓点、交接顺序和轮角回退 |
| E：低速接管 | 在D组通过后，以低速继续转动并完成同类接管 | 动态接近与交接是否可行 |
| F：连续范围 | 根据前面结果扩大至±180°，除往返外加入同侧反向与跨零，例如平滑的0→+70→+25→−40→+110→0 | 不回零也能连续改变目标，保留记忆及抓握状态；观察人类式主导／释放关系 |

B组轮速参考先取5°/s，用平滑加减速。目标处和零位各保持3秒；A组单独验证10秒保持。遇到机械或碰撞限制时停止该候选，定位原因后再改方案；不要求先完成所有单手大角度片段才允许接管。

参考与日志同时保存本段目标累计角、随时间推进的参考角和实际角；后续360°、540°操作需要完整目标来区分同一中间角度下的不同任务。后续R0落实支持居中±540°的设备和对应模型，现有G29的±450°阶段测试不代替该目标。大角度完整操作在P4验收，P0记录可行交接片段供其使用。

先调试低负载，再按测得的名义回正负载曲线逐级增加，例如25%、50%、100%，记录每一级实际力矩。回正曲线可能依赖轮角和轮速，不能默认恒力矩或线性弹簧就等于实物。

R0实测尚未完成时，可用预声明的合成负载做工程探索，明确标为未标定仿真结果；不能将它计作实物对应负载验证。进入参考学习前至少要有非零负载下的完整基础片段，以及可追溯的负载参数与适用边界。零位的回正力矩可能为零，单手接触零位轮盘不能直接算作单手承载验证。

每个名义案例先做完整执行和可重放验证。加入扰动前，冻结扰动范围、种子和重复次数；不能临时选择有利初态。第一轮工程探索不作95%成功率结论。

## 4. 怎样判断通过

下面是P0调试门槛，不替代总计划的正式论文精度目标。修改门槛必须在下一轮运行前记录版本及原因。

| 检查 | P0条件 |
| --- | --- |
| 完整执行 | 完成规定去程、停留、返回和零位保持，无中途重置或外部扶持 |
| 角度误差 | 小角度完整任务运动RMSE≤2°，两处停止末段1秒的峰值误差≤2° |
| 关节与执行 | 不越真实限位，手臂最小关节余量>2°，电机输出不超配置边界 |
| 碰撞与穿透 | 无机器人自身／座舱非法碰撞；轮圈最大接触穿透<0.5 mm；数值状态有限 |
| 拨片与轮辐 | 非轮圈接触法向力>0.05 N记为失败，保留发生时刻和几何对 |
| 初态和保持支撑 | 主动支撑手四指、掌部和拇指的轮圈接触采样占比各≥95%，统计阈值0.05 N |
| 转动与接管 | 记录每指接触、逐手轮轴力矩和轮角回退，不强求所有手指每刻都接触；接管最大回退先以≤2°为工程目标 |
| 轮轴来源 | 任务阶段无居中辅助、轮轴角度伺服或直接设置轮角；只有已声明的外部负载 |

腕姿先报告各轴角度、前臂与手掌夹角和随任务的变化；2号不套用1号的10°／15°检查。运动工作范围结合机械条件和实物响应确定，在扩大负载或范围前另行冻结，不能把“没有越总限位”当作舒适姿态的充分证据。

超过0.05 N的接触阈值仅用于一致地计数，不证明抓握力闭合。回正负载下新手能否承载，还须结合实际接触力矩和轮角变化验证。接触力上限按手部输出能力与R0实测制定，未确定时不进入实物加载试验。

仿真力、轮角、关节状态和异常按每个物理步记录；按50 Hz或更高频率导出可视化接触统计。只有外部评价器可以决定通过，不能从控制器内部阶段完成标志直接判成功。

## 5. 需要产出什么

本轮运行目录 `outputs/p0_complete_20261107/`，正式报告入口 `results/p0_complete_20261107/README.md`；之前重启试验在 `outputs/p0_restart_20261107/` 保留。每次调整使用新的子目录，保存失败轨迹；不覆盖旧结果。

- 运行清单：配置、哈希、种子、负载、观测来源、碰撞排除和辅助移除时刻。
- 逐步轨迹：实际／参考轮角与轮速、26维命令与反馈、关节余量、接触和力矩、执行器状态。
- 可行性图：轮角、抓点、主导手、负载与接管窗口，附腕姿及约束边界。
- 完整视频：至少包括小角度往返、两种单手支撑、双方向接管；失败片段也保存。
- 汇总：每个案例的通过条件、首个失败时刻、原因和下一轮唯一主要改动。

## 6. 进入学习阶段的条件

在版本明确、预声明非零回正负载的仿真运动环境中，具有双方向小角度往返、左右单手支撑和两个方向至少各一组可行接管片段。实物反馈与负载清单归后续R0，不再阻塞本轮仿真P0；合成负载不能替代实物标定。±180°尚未全程通过时，保留失败边界，先用已验证片段训练和补足工程能力，不宣称全范围已具备。

显式控制失败先查几何、可达性、接近路径、摩擦负载和执行链。没有工程可行性依据时，不用大规模RL掩盖问题。接管窗口可以有多个候选，后续参考引导策略学习在其中协调，不将它们直接变成部署硬阈值。


## 7. 本轮控制版本和范围约定

基础抓握不再逐关节精修。工程控制使用离线姿态优化、主导手转动、另一手释放、接近与承载转移。腕姿只作定性与数值报告，拟人性尚未由人类示范量化。

26维目标变化率保持20 Hz；在500 Hz物理步内对相邻目标线性插值，保持原目标速度边界。接触反馈先对一个控制周期内的物理采样取平均，避免20 Hz瞬时抽样造成混叠；原始500 Hz接触数据仍完整用于评价。手掌贴合由小幅径向目标修正完成，最大3 mm，属于显式工程基线的仿真接触反馈，不作为后续学生的免费传感器。

D组先验证±30°停稳交接。E组探索±30°起始窗口失败后，使用±15°起始窗口，在±15°到±35.5°以1°/s继续转动并交接；外部任务时钟不停。E的回退指标使用相对原时间参考的误差变化，不能把合法的20.5°前进当成回退。

F组在同一次物理执行中做0→±70→±25→∓40→±70→0，含运动交接、同侧反向和跨零；交接期间的过渡点不改写最终任务目标。另保留向±180°扩展的探索结果与失败边界。未全程通过±180°时，只能宣布已验证范围和基础入口通过，不能宣布全范围策略完成。

同一阶段出现多次时，每个连续保持段分别验收；每次交接分别检查交叠、新手10秒独立支撑和旧手离开。F的近零交接不作为非零负载承载证据，非零负载能力由C/D/E单列验证。

F组最终运行启用有界四指接触恢复（`--contact-grip`）：仅在贴合并闭合后，对低于0.15 N的指部接触缓慢增加原驱动目标，增益0.3 rad/(N·s)，最大增加0.15 rad，退开后清零。数值门槛不变，A–E不启用该选项；实物或学生是否具备相应接触反馈另行验证。
