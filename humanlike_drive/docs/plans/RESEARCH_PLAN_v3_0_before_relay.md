# Humanlike Drive研究计划：掌部主导、手指辅助的拟人转向

版本：v3.0，2026-11-07。[第2.3版](RESEARCH_PLAN_v2_3_before_palm_primary.md)保留供追溯。

**先验证机械手能否依靠稳定的掌部接触传递转向力矩，再研究人类式的主导手分工、释放、接管与长时序角度追踪。** 手型适应Inspire的有限自由度，不要求复制人手侧摆，也不逐指追求包得更深。

之前左右90°成功案例已[独立备份](../../results/archive/20261107_pre_palm_primary/README.md)，只作历史参考。旧结果仍按原协议成立，但不作为本主线的初态、专家数据或通过证据。新方案目前处于计划阶段，新的P0尚未执行。实物标定继续在[R0](R0_HARDWARE_CALIBRATION.md)后续单列。

## 1. 这次改变什么

| 项目 | 当前决定 |
| --- | --- |
| 抓握目标 | 掌部适度压紧，四指轻度弯曲辅助稳定，拇指在可达时提供侧向支撑 |

需要检验的假设是：缺少手指侧摆时，掌部仍能成为主要传力区域，四指帮助轮圈留在掌部，拇指改善侧向稳定。**这仍是假设，不能凭外观或法向接触力下结论。**

## 2. 怎样理解“掌部带动方向盘”

压紧产生法向力，手臂沿轮圈圆周运动，通过摩擦传递切向力和转向力矩。理想圆环上，朝轮心的径向压力本身不直接产生绕轴转矩。近似关系为“转矩≈轮圈半径×切向力”，切向力又受摩擦和压紧力限制。

“掌部主导”指掌部能稳定传递主要转矩；不是掌部法向力最大，也不是压力越大越好。手指接触同样可以贡献转矩，允许其自然参与。

先采用以下控制分工：

- 手臂沿轮圈运动，并在局部接触法向上柔顺地维持贴合。轮盘平面内径向、轮轴方向和实际接触法向分开定义，不沿用含糊的“径向修正”。
- 四指采用少量可调的轻握参数，拇指保持侧向支撑；调整仍映射到原六驱动，不增加自由度或改变mimic。
- 接触不稳时先检查位置、朝向、速度和负载，再有界调整贴合与闭合；限制预紧、变化率和电机输出。
- 新手接触并能够承载后，旧手再卸载和退开。先验证停稳接管，再做持续运动接管。

仿真接触真值可供P0控制和教师使用；学生能否获得实际力反馈由R0决定，不能预先假定硬件具有掌部触觉。

## 3. 新P0：先证明这个方式可用

具体案例和门槛见[掌部主导P0协议](../experiments/PALM_PRIMARY_P0.md)。旧协议及评价器保持原义，新试验使用独立版本与输出目录。

| 步骤 | 具体做法 | 要得到的证据 |
| --- | --- | --- |
| P0-A 接触与传力 | 校核掌部碰撞体；建立少量自然腕姿候选；双手及左右单手保持；测试明确非零的双向负载 | 接触位置、掌／指转矩、滑移、负载平衡及有限输出 |
| P0-B 小角度双向转向 | 从±15°开始，到±30°、±60°，完整转动、保持和返回，再加入途中反向、跨零 | 掌部随运动持续传力，没有靠指端或非轮圈部件卡住完成动作 |
| P0-C 稳定性与接管 | 冻结参数后测试摩擦、负载和初态扰动；比较手指辅助作用；先停稳再低速接管 | 适用范围、失效边界、承载交叠与滑移 |

不先追求重现旧90°。以后即使测试90°，也要以新接触机制、控制和评价完整重做。

左右手分别验证，不把镜像当作等价成功。若稳定转向仍依赖四指末端主导承载，报告机制假设尚未成立，再调整整手位置、抓点或范围，不靠增大握力掩盖。

**新验收不要求四指、掌部、拇指各自全程有接触。** 重点是支撑手掌部贴合稳定、转矩来自轮圈接触、受载滑移可控，以及接管有效。指部接触作为诊断，不为凑齐接触点强行闭合。

P0只证明冻结配置与声明范围下可行，不等于拟人性或泛化已经验证。P0-C完成后，才进入主线参考构建与教师训练。

## 4. P1：建立行为参考

人类示范用于提取双手分工、释放／接管顺序、腕部运动和重抓区域，不逐关节复制手指姿态。

先用少量视频梳理顺序，记录来源及观察不清的事件；具备条件后采集同步视频、连续轮角和双腕相对轮盘运动。覆盖±180°连续追踪及360°、540°操作，540°使用支持该行程的设备。

用新P0机制生成可物理重放的机器人参考，覆盖掌部贴合、反向修正、单手主导、停稳／运动交接。初步约20段用于检查覆盖，数量不作为充分性证明。

人类视频、仿真机器人参考和真实机器人示范分别归档。旧90°和旧连续序列不混入主线训练集；若做历史对照，另列场景、控制、数据和负载差异。

## 5. P2—P4：学习范式与网络

继续采用“可行接触控制与人类交互参考 → 仿真RL教师 → 历史学生 → 实物验证与必要适配”。抓握假设变化不需要立刻推翻学习框架。

### 5.1 执行接口

双臂各7关节、双手各6驱动，共26个独立执行器。保留原限位、有限输出和mimic。策略20 Hz、物理500 Hz为起点，底层对限速目标插值。

第一版仍用26维目标变化率。新P0的掌部贴合控制先作为工程基线和参考生成工具；若后续将其纳入策略执行层，须先验证、另定接口，并让比较方法遵守相同执行边界。学生执行器不能暗中保留读取仿真接触真值的反馈器。

### 5.2 第一版网络

```text
可部署观测 → 归一化 → MLP(256,128) → GRU(128) → 历史表示h
教师：接触、摩擦、负载等特权量 → 32维z ───────┐
学生：从观测历史估计32维z_hat ───────────────┤
                                          ↓
                               动作头 → 26维动作
```

部署观测包括实际可读臂手反馈、累计轮角和轮速、标定后的腕轮关系、上一动作及已下发目标。任务输入包括本段目标角、随时间推进的参考角／轮速及实际提供的有限预览。噪声、延迟和手驱动字段按R0修正，不把命令当实测。

教师用PPO，critic读取完整物理状态；可靠新参考可用于短程BC初始化，记录其数据成本。教师学会接触和协同后，以自主滚动及DAgger式数据聚合训练学生，在学生实际访问的状态上重新给专家标签。

最终只部署一个带记忆的策略，不按角度切换网络。手写接管顺序用于P0与参考生成，最终不作为阶段控制器。历史能否识别滑移由实验验证，不预设记忆能替代触觉。

### 5.3 课程、奖励与比较

课程依次为：掌部保持与小角度反向 → 单手主导与释放 → 接管 → ±180°连续追踪 → ±360°操作 → ±540°操作 → 混合长序列。

奖励保留角度／轮速跟踪、参考交互顺序、接管负载连续性和执行约束；加入掌部稳定贴合、受载滑移和过大预紧评价。释放手不施加接触要求，不奖励增大压力，不要求每指一直贴住。阈值经P0确定，不直接复用旧“四指全部接触”门槛。

主比较仍为：参考引导与无参考RL、严格时间参考与局部时间／姿态适配、教师与学生。ACT、Diffusion Policy使用同一批新机器人专家数据作为模仿对照。

## 6. 最终任务与实物实验

轮角使用连续累计值，约定右正左负，并标定与仿真／编码器符号的对应。

| 任务 | 必须验证的行为 |
| --- | --- |
| ±180°连续追踪 | 平滑同侧增减、途中反向、跨零、停留、继续转动，整段不重置记忆和抓握状态 |
| 左右360° | 相应接管重抓、终点保持与受控回正 |
| 左右540° | 更长的交替操作、保持及回正 |
| 统一长序列 | 同一策略持续执行三类任务，检查角度、抓握和控制目标漂移 |

接管时机由参考和机器人可行窗口共同确定，不固定每180°换手，也不只凭当前轮角判断任务。连续序列例如平滑的 `0→+70→+25→−40→+110→0`，不因换手暂停任务时钟。

G29居中±450°行程不足以完成居中向任一方向540°。R0需落实支持该行程的设备及对应模型；修改止挡须另记版本，不冒称原装G29。540°仍是研究目标。

实物在后续[R0](R0_HARDWARE_CALIBRATION.md)完成几何、负载、摩擦、执行能力、延迟和反馈标定。先真实掌部贴合与小角度，再单手承载、接管、±180°、360°、540°和统一序列。冻结学生后做首次迁移；必要时修正仿真或采集真实示范，通过BC／受约束微调适配，分开报告成本和结果。

没有真实掌部力或逐手力矩测量时，只报告可测轮角、标定负载与可见滑移，不用仿真曲线替代实物证据。

## 7. 论文要回答什么、怎样证明

研究问题：**受机械手运动能力约束时，能否以掌部主导的接触方式承载方向盘，并利用人类式双手交互参考，让一个策略实现长时序双向连续转向和大角度操作？**

三组证据分别报告：

1. 接触机制：掌部／各指轮轴力矩、滑移、可承受负载，以及轻握手指的稳定作用。指端主导对照应在同一新场景下重做，历史90°不能直接作为同条件对照。
2. 学习与行为：参考是否帮助学会释放和接管，局部时间适配是否有效，学生是否保留教师能力；与人类参考的分工、顺序和腕部运动是否一致。
3. 统一与迁移：三类任务及混合序列的完整成功率、误差、漂移、滑脱和非法碰撞；首次实物迁移与适配后的差别。

正式RL至少3个训练种子，提前冻结预算、划分和评价任务。按完整轨迹／会话划分留出集，调过参数的任务只算回归。初始研究目标仍为运动RMSE≤1°、每次停止末段3秒峰值≤1°，保持3秒／10秒，成功率目标≥95%；均非已有能力，正式运行前结合测量精度冻结。

保留DeepMimic／BeyondMimic的参考引导物理控制思路、DexScrew的旋转与教师学生／真实数据适配分工、DAgger的闭环蒸馏，以及ACT／Diffusion Policy对照。来源与边界见[第2.3版参考表](RESEARCH_PLAN_v2_3_before_palm_primary.md#10-项目组织参考和下一步)和[论文库](../../../references/README.md)。掌部主导假设来自当前硬件分析，尚无本项目验证结论。

## 8. 接下来按什么顺序做

1. **已完成：**备份旧左右90°及源码、报告，保存旧计划，将旧路线标为历史参考。
2. **下一项P0-A：**校核掌部碰撞体，建立自然腕姿下的贴合候选，实现按部位统计轮轴力矩、接触和滑移的诊断，完成左右手非零负载保持。
3. P0-A成立后执行P0-B，再做P0-C；每阶段给出完整视频、曲线和失败边界。
4. 依据新证据冻结初态、控制和评价，再构建P1参考、训练教师学生；R0独立安排，在实物部署前完成。

新运行放在 `outputs/palm_primary/<run_id>/`，报告放在 `results/palm_primary/`，在实际执行时建立。继续沿用环境、控制、任务和评价分工，新控制与评价独立命名，旧入口保留供回放。

本次仅完成计划重定与历史备份，没有修改抓握、接触参数或控制代码，没有启动新的物理试验。
