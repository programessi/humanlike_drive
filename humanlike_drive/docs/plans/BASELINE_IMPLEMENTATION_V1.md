# B0候选基线草案：参考初始化、PPO教师与历史学生

版本v1.0草案，2026-11-07。状态：未实现／训练，第二层候选之一。依据[三层研究计划v4.0](RESEARCH_PLAN.md)，本文不再是当前默认主线；先完成物理入口和已有方法筛选，再决定是否执行此路线。下面保留当时的具体设计供适配比较，不表示已经选定论文方法。显式协调器、转移可行性或其它创新模块也等待第二层证据。

**目标是先获得一套能够闭环工作的统一策略：掌部稳定传力，双手完成局部双向操纵和重复接管，逐级覆盖±180°连续追踪、360°、540°和回正。** 它使用已有成熟方法，不以结构复杂或新颖为目标。

## 1. 如果选择B0，采用以下训练与部署线路

```text
新P0：显式控制证明接触与接管可行
                    ↓
保存可物理重放的新机器人参考
                    ↓
短程BC初始化特权教师
                    ↓
参考引导PPO，闭环改进同一个教师
                    ↓
历史学生：初始化拟合 + DAgger式自主滚动
                    ↓
冻结学生，完整仿真评价
                    ↓
R0实物标定 → 首次迁移 → 必要真实数据适配
```

当前不用三套角度策略、不单独训练接管网络、不加入转移可行性预测或承载余量预测。GRU仅先用于学生历史适配，不同时增加循环PPO训练难度。

BC初始化使用**新场景中物理执行成功的机器人数据**，不是直接克隆人体手指，也不使用旧90°数据。其数据与算力成本计入基线总成本；不把它描述为从零PPO。

## 2. 工程入口：显式控制负责找路，不替最终策略执行

按[新P0协议](../experiments/PALM_PRIMARY_P0.md)完成掌面几何、非零负载保持、小角度与接管。

显式控制先用平滑腕部路径、有限输出和原mimic，建立“操纵手传力—接收手接近—承载转移—原手退开—返回准备区”的片段。允许P0控制器使用仿真接触反馈，逐步验证新手接管后继续转动与反向，并完成第二次接管。

先完成最短可闭环序列，不要求脚本先把540°全程做完才开始学习。后续每扩大工作区，应先得到相应物理可行性证据和有效训练起点；大角度未完成就如实标注，不把短片段拼接成物理成功轨迹。

部署学生只输出26维动作。运行器负责提供轮角指令、限速／限位和记录，不根据轮角帮它选择主导手，不触发预设抓握，不在接管时重置目标或记忆。底层也不能偷偷保留仿真接触反馈器。

## 3. 基线策略究竟看什么、输出什么

### 3.1 部署观测o

| 组别 | 字段 | 原因 |
| --- | --- | --- |
| 臂与手 | 14个臂关节反馈、12个手驱动可读反馈及可靠速度 | 当前构型和执行响应；字段以R0硬件为准 |
| 腕轮关系 | 左右掌／腕相对轮轴基座的位置、朝向和可靠运动估计 | 当前接触区域、接近与退手位置 |
| 轮盘 | 连续累计角、轮速，必要时额外sin／cos | 区分整圈进度，同时表达周期几何 |
| 任务 | theta_goal、theta_ref、omega_ref、跟踪误差、有限预览 | 知道当前应转动、保持还是返回 |
| 执行历史 | 上一动作、已下发26维目标及目标—实测偏差 | 区分主动闭合、压紧不足和执行滞后 |

轮轴坐标系固定在安装基座上，轮盘材料运动另由轮角表达。编码器角不取模。首版任务预览可取0.5秒，只提供实际存在的外部指令；所有对照一致，不给未来真实状态。

学生不读真实接触、真实摩擦／负载、参考片段号、脚本阶段、未来接管时刻。对缺失的手部传感，不用命令或完美mimic真值冒充反馈。

### 3.2 动作u

采用26维目标变化率：左臂7、右臂7、左手6、右手6。教师与学生接口一致。

`q_target_next = bounded(q_target + dt * scale * u)`

bounded包括原关节限位、目标变化率上限、目标相对实测偏差上限；随后由有限输出PD执行。mimic仍由原URDF关系约束。掌压由位置与接触物理产生，学生不能直接施加一个绕过执行器的掌力。

策略起点20 Hz，物理500 Hz，底层目标插值。执行边界在P0后冻结，不为不同角度偷偷切参数。策略可以适度调整手指，不要求四指全程接触，也不奖励握力越大越好。

## 4. 教师：先采用普通MLP与PPO

```text
当前部署观测o → MLP → e(128) ─────────┐
仿真特权物理量p → MLP → z(32) ───────┤
                                    ↓
                              MLP(256,128)
                                    ↓
                           26维动作均值 + 探索方差

critic：完整物理状态、当前指令及执行状态 → value
```

教师特权量可含真实掌／指接触、相对运动、外负载、摩擦及执行参数；critic额外读取完整机器人和物体状态。actor不得读取未来成功标签、预设接管时刻或下一动作答案。

26维动作可以在代码中分成左右臂手四组做尺度与日志，不为分头输出增加四套独立决策策略。教师采用非循环MLP，先降低实现和优化难度；当前驱动目标、速度与控制内部状态要显式提供，不能让执行器隐藏状态破坏教师的状态表达。

先用新参考中的部署观测、特权量和**实际下发动作**做短程BC。动作标签从20 Hz控制命令保存，不用qpos差分推算，以免把执行滞后当成意图。BC早停由留出完整轨迹与闭环表现确定，不只看离线动作误差。

随后用PPO继续训练同一个教师。探索时有标准动作分布，评价采用确定性均值。初始可用常规PPO设置，如clip 0.2、学习率3e-4；并行数量、rollout长度、折扣及总预算先根据吞吐和任务时长小试确定，再在正式比较前冻结，不预先承诺现有MuJoCo场景能直接大规模GPU并行。

## 5. 基线奖励：保留任务与参考，不增加创新模块

| 项目 | 基线中的作用 |
| --- | --- |
| 轮角／轮速跟踪 | 当前时刻跟踪、停止保持、返回零位；外部参考时钟持续推进 |
| 腕部和交互参考 | 引导合理接近、主导／释放、有序交接和自然腕姿，允许局部姿态差异 |
| 掌部贴合 | 承载阶段保持有效掌面接触，释放阶段不强求接触；过大压力受罚 |
| 动作和执行代价 | 限制过快变化、过大预紧、饱和和不必要手指运动 |
| 物理失败 | 非法碰撞、越界、数值异常、不可恢复失握等独立终止或计失败 |

参考可提供训练时的腕部目标与交互标签，但只进入损失／奖励和评价器，不作为部署阶段控制器。阶段顺序用固定版本的参考及简单局部对齐规则处理，先不加入可行性网络或学习到的时间适配器。

不要奖励“多换手”或“所有手指都接触”。接管后继续操纵作为训练任务的一部分；基线不添加专门预测未来可操作性的头。奖励权重、误差尺度、对齐窗口和失握条件在每版试训前保存，改动后另记版本。

## 6. 课程：增加任务长度，不增加策略数量

| 级别 | 学什么 | 完整检查 |
| --- | --- | --- |
| L0 | 掌部保持、轻握、小幅纠偏 | 双手及左右单手，非零负载10秒保持 |
| L1 | 左右手分别双向操纵，停止、反向、回正 | ±15°／30°／60°，再按新可行范围扩大 |
| L2 | 释放、接近和一次承载接管 | 两个接管方向，停稳后到低速运动 |
| L3 | 接管后继续操作，再做第二次接管 | 旧手返回准备区，连续物理执行，无重置 |
| L4 | ±180°内连续追踪 | 同侧增减、反向、跨零、保持及返回；允许必要接管 |
| L5 | 360°及回正 | 两方向去程、保持、返回全过程 |
| L6 | 540°与混合长序列 | 匹配行程设备／模型上，两方向、多次接管和漂移 |

各级从上一检查点继续训练同一个教师，并混入已掌握任务防遗忘。训练可以从合法中间状态开始，但状态、控制目标和起点前上下文需可追溯。评价从规定初态完整执行。

参考先覆盖当前课程；扩大任务时补充物理可行的新参考与连续rollout。不能把540°通过写成只用180°训练就自然泛化，除非冻结前者训练所得策略后独立测得。

原G29居中±450°，L6居中±540°需要独立版本的长行程轮轴。调整行程／惯量／负载时保留模型来源，同条件比较时所有方法使用相同设备版本。

## 7. 学生：用历史替代特权信息

```text
当前部署观测o → 同类编码器 → e(128) ───────────┐
观测／命令历史 → GRU(128) → z_hat(32) ─────────┤
                                            ↓
                             与教师兼容的MLP动作层 → 26维动作
```

GRU隐状态包含接触与执行历史，但累计轮角直接由编码器提供，不靠GRU数圈。首先复制教师兼容的观测编码／动作层，拟合历史适配模块；随后进行DAgger式学生自主滚动，冻结教师在学生访问状态上给标签，必要时联合微调学生的编码和动作层。

训练损失先采用动作拟合与隐变量拟合：`L = L_action + lambda_z * L_latent`。lambda_z在开发集确定，不让预测物理隐变量的数值误差掩盖动作与闭环表现。

由于教师为无记忆MLP，重新标注不需要重建教师GRU；学生仍需连续序列、episode边界和预热训练。部署仅在真实episode起点重置记忆，不在接管或目标段变化时重置。

教师能利用瞬时接触真值而学生未必能推断，蒸馏不保证无损。先分别报告教师和学生的局部操纵、接管与完整长序列；差距大时检查特权依赖、反馈字段和时序，再判断是否需要真实触觉或实际纠正数据。

## 8. 基线怎样验收与冻结

不把“保存了一个模型”作为基线完成。每级需保存实际配置、数据来源、代码快照、完整任务评价、视频和失败；停止／接管片段分别检查，不能只看平均轮角误差。

- 工程入口沿用新P0：运动RMSE≤2°、停止末1秒峰值≤2°，其余接触、滑移、非法碰撞、原限位与有限输出按协议；P0不能替代学习结果。
- 教师和学生沿用同一任务及执行边界分别报告。基础回归先使用提前冻结的左右方向、序列与扰动，不边测边删失败；这是开发结果，不作正式泛化结论。
- 正式基线至少3个训练种子，预先冻结预算、检查点选择与留出任务；报告成功率、样本数、不确定性、运动／停止误差、交接回退、失握、漂移和碰撞。
- 三类任务和混合长序列分别列通过范围。达到360°但540°失败时记为部分能力基线，不称完整工作已完成；失败本身可成为后续改进的比较起点。
- 为未来方法保留固定观测、动作边界、任务划分、评价器及基线检查点；新方法多用的训练、数据和监督单列。

正式论文精度目标仍参照研究计划：运动RMSE≤1°、停止末3秒峰值≤1°、保持3秒／10秒、完整成功率目标≥95%。这些是待验证目标，不是基线已有能力；实物测量精度不支持时在正式试验前解决或另定。

## 9. 实物入口与适配

按[R0](R0_HARDWARE_CALIBRATION.md)落实反馈、有限执行、坐标／轮角、负载和延迟，先用真实低速小角度与单手承载检查模型。冻结学生记录首次迁移全部尝试，再逐步到接管与完整任务。

必要适配先修正可测模型差异，再补充可靠真实专家／纠正数据做BC或受约束微调。自主失败不自动成为专家标签。首次迁移、适配后结果及全部成本分别列出；仿真接触曲线不充当真实力测量。
