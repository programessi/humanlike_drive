## 2. 论文准备回答什么问题

拟研究的问题是：**能否模仿人类在常规转向与大角度换握中的行为分工，用同一双臂灵巧手策略实现±180°内双向连续追踪，以及360°、540°的操作、保持和受控回正，同时在回正负载下维持可靠承载？**

重点验证三个假设：

1. 人类示范中的释放、接管和重抓关系，能帮助机器人更快学会有效交接。
2. 允许交接时机与局部姿态随机器人状态调整，比严格复制参考时间更稳。
3. 只使用部署反馈和历史的学生，能保留教师关键能力，并完成实物长序列。

10点／2点是实验条件，不单独作为论文创新。现有驾驶员照片和视频抽帧只支持定性姿态参考，不能当作已采集的人类动作数据或拟人性证据。

### 2.1 任务定义

角度使用连续累计值。任务层约定右转为正、左转为负；实现时标定它与编码器、MuJoCo关节符号的映射。绝对零位是轮盘机械居中位置。

“转动 → 保持 → 受控回正 → 零位保持”用于基础调试和大角度完整操作。±180°连续任务还必须包含不先回零的同向增减、途中反向和跨零追踪，例如平滑执行 `0→+70→+25→−40→+110→0`。这些数值是序列中的途经目标，不是瞬时轮角跳变。整段不重置网络记忆、抓握状态或执行目标。

| 层次 | 范围与目的 |
| --- | --- |
| 基础层 | 左右30°、60°、90°，验证转动和返回 |
| 连续行为 | −180°到180°内任意可执行的平滑参考，包含停留、同侧反向和跨零；避免不必要的换手 |
| 360°操作 | 左右方向均完成至360°、保持及返回，模仿相应的释放、接管和重抓序列 |
| 540°操作 | 左右方向均完成至540°、保持及返回，验证更长的交替接管与承载记忆 |
| 统一长序列 | 在合法行程内连接连续转向、360°和540°任务，分段目标变化时策略持续运行 |

当前G29模型止挡为−450°到450°，居中起步到540°超出行程。**540°仍是必须完成的研究目标，行程问题是需要解决的设备条件，不能据此将任务降为可选扩展。** R0必须确定支持居中向左右各540°的轮轴／设备方案，可使用保留类似轮圈的长行程被动加载台架或其他合适设备。相应仿真另记模型版本，并匹配对应实物；原G29在其真实行程内继续用于阶段验证，不将修改止挡后的模型冒称为原装G29。

若另做偏置初态下540°位移试验，分别报告初始绝对角、目标绝对角和累计位移，该试验不能替代居中起步540°的目标。

### 2.2 模仿哪些行为，怎样保持统一

常规角度段模仿人类的主导手控制、另一手适时松开／伴随以及自然的反向修正；大角度段模仿新手接近、接管、旧手释放与重抓的有序循环。360°和540°的操作序列分别建立参考，次数与抓点由示范及机器人可行性共同确定，不预设每180°机械切换一次。

这是一个策略覆盖不同交互行为。任务输入提供本段目标累计角 `theta_goal`，以及按时间推进的 `theta_ref`、参考轮速和实际可用的预览；连续任务在线更新目标，大角度任务保留360°或540°终点。累计实际轮角、双臂手状态和历史帮助策略判断当前如何继续。不能只凭“当前轮角是否超过180°”选择动作，因为360°和540°操作也会经过0–180°。

行为评价与跟踪精度分别报告：主导／释放关系、交接顺序、无效换手、重抓位置及腕部运动与参考的接近程度。允许时间和姿态适配，但不把人类交互参考弱化成一个只需达到终点的角度奖励。只有采集到相应人类示范并验证后，才作行为模仿效果的结论。

## 3. 第一步：验证2号怎样转起来

先用显式控制，不启动大规模训练。具体操作见[2号运动可行性协议](../experiments/TEN_TWO_FEASIBILITY_V1.md)。

### 3.1 建立可用于运动的环境

- 保留坐姿、座舱、G29轮圈和真实拨片碰撞，遵守原始机器人关节限位和Inspire六驱动mimic。
- 建立独立版本的运动环境，开启非相邻机器人部件的自身碰撞响应；合理排除相邻关节装配面，不用排除整只手或整条手臂来掩盖碰撞。
- 在运动环境重新核对2号接触和稳定性。重力补偿、执行器增益及有限输出与实物接口对应；工程调整要记录，不为单个角度单独改变参数。
- 轮轴保持被动。先低负载调试，再加入与实测对应的回正力矩、摩擦和阻尼。正式承载任务包含非零回正负载。

当前查看场景保留作检查工具，原5秒结果不能直接算作新运动环境通过。

### 3.2 分开回答“够得到”和“推得动”

先离线检查双手保持、右手主导／左手释放、左手主导／右手释放等模式。可将轮盘置于候选角度求IK，筛查关节、腕姿和碰撞限制；这种摆姿势检查不算完成物理转向。

随后从2号出发，依靠有限电机和真实接触推动轮盘，依次测试±30°、±60°、±90°，每次包含保持与返回。轮速参考先取5°/s，使用平滑加减速，避免目标瞬时跳变。

右转分别检查左手主导、右手主导和双手协同的可行片段，左转镜像检查。根据实际接触和执行结果确定方式，不仅根据手位于上半圆就指定主导手。

### 3.3 实测接管窗口

在主导手接近腕姿、关节余量或碰撞限制前，搜索另一只手能从外侧接近轮圈的位置。先停稳接管，再尝试低速不停顿接管。

参考顺序为“原手支撑 → 新手建立有效接触 → 转移承载 → 原手松开 → 原手重定位”。不要求双手每刻紧握，也不将接触力刚超过阈值等同于承担了所需力矩。

产出可行性图：在什么轮角、抓点、臂姿和负载下，哪只手可以继续转动或开始接管。10点／2点与9点／3点的接触相位不同，需要重新测量窗口；重抓后，后续窗口也随抓点和臂姿改变，不能只按累计轮角计算。

如果显式控制也无法完成片段，先修正抓点、接近路径、安装关系或执行参数。2号的握持方式是起点，必要局部调整另记版本，不为保留初始外观牺牲可行性。

## 4. 示范与交互参考怎样建立

主数据从10点／2点附近出发。旧场景、旧抓握快照和旧策略数据不进入新训练集；历史失败用于安排诊断。

先采集约20段作为小样本起点，按三类分别安排：±180°内连续追踪（含途中反向和跨零）、360°完整操作、540°完整操作。每类覆盖左右方向、保持及返回；540°采集使用支持该行程的设备。优先补齐行为变化与接管片段，数量不作为充分性的证明，也不声称20段已足够。

每段尽量同步记录视频、连续轮角和双腕相对轮盘位姿，标注接触区域、释放和接管事件。观察不清的接触标为未知；没有力测量时，视频接触不能直接作为真实承载力矩标签。

从示范提取物体运动、手腕与轮圈关系和动作先后顺序，再映射到机器人可行姿态，不逐关节复制人体动作。接管抓点结合可行性验证确定，不要求每次固定抓到3点。

若三维采集暂不可用，先用视频明确交互顺序，再以新仿真显式控制生成可物理重放的参考。人类视频、机器人合成轨迹和实物机器人示范分开记录。合成数据不计作人类动作数据。

## 5. 学习路线：参考引导的RL，再训练历史学生

```text
2号物理转动与接管验证 + 实物接口、负载测量
                       ↓
建立人类交互参考和可行机器人轨迹
                       ↓
PPO教师：学习转动、保持、释放、接管和回正
                       ↓
学生自主执行，教师在学生访问的状态上重新给动作标签
                       ↓
一个使用部署反馈和历史的循环策略
                       ↓
实物逐级验证；必要时修正仿真或补充真实示范适配
```

局部保持、单手转动、接管用于课程和初始化，最终合并为一个策略。部署时不按目标角度切换多套网络，也不依赖手写换手状态机。

不要求先完成大规模BC。若已得到可靠的新场景专家轨迹，可短程BC初始化教师，再做RL，单独记录其数据成本。ACT和Diffusion Policy作为同机器人专家数据条件下的模仿对照。

DexScrew支持仿真旋转技能、历史学生与真实数据适配的分工，其完整实物路线还包含技能辅助遥操作和真实触觉／本体数据BC；不能据此保证本项目纯仿真直接迁移成功。

### 5.1 课程顺序

1. 保持与小角度往返，逐级加入非零回正负载。
2. 单手主导与另一手释放，避免双手相互抵抗。
3. 已验证的交接片段：先停稳交接，再低速交接。
4. ±180°内双向连续追踪，加入同侧增减、途中反向、跨零、停留和继续转动；不只训练从零出发的往返。
5. 左右360°的专门换握操作、保持和回正，混合训练连续角度任务。
6. 左右540°的更长换握操作，再混合三类任务形成统一长序列；检查相同中间角度下不同目标、抓握状态和操作历史。

训练允许从合法中间状态起步；最终任务从规定初态完整执行，中途不得重置轮角、目标、抓握锚点或记忆。

## 6. 第一版网络和动作怎样设计

### 6.1 动作直接对应26个独立执行器

双臂各7个关节、双手各6个独立驱动，共26维。动作是归一化的位置目标变化率，在控制周期内积分为目标，经限速、限位和有限电机输出执行；从动关节继续使用原mimic。

将已下发的位置目标和上一动作输入策略，对目标相对实测位置的偏差加界限，防止积分成过大预紧。各维速度尺度根据执行和实物响应确定，不套用同一增量。

这样策略能直接调整肩肘腕和手指，第一版不依赖尚未验证的在线IK分支。IK用于参考生成及显式基线。旧24维双腕／双手动作表示留作后续比较，不同时实现两条主执行链。

### 6.2 部署观测

| 输入 | 来源与限制 |
| --- | --- |
| 双臂关节位置、速度 | 实际反馈，建模滤波与延迟 |
| 手驱动反馈 | 以实物可读字段为准；不将命令冒充实测，缺失反馈在仿真也相同处理 |
| 双腕相对轮盘位姿 | 正运动学、轮轴标定和轮角估计，考虑误差，不读取无噪声仿真真值 |
| 累计轮角、轮速 | 编码器及连续展开角，轮角不取模 |
| 任务信息 | 本段目标累计角 `theta_goal`、当前时间参考 `theta_ref`、参考轮速、误差及实际提供的有限预览 |
| 执行历史 | 上一动作、已下发目标及有效执行器内部状态 |

预览以0.5秒为试验起点，所有方法使用相同可用指令。学生不读取演示片段编号、预设换手时刻或真实仿真接触标签。历史不足以判断接触时，比较实际传感反馈或真实数据的收益，不假定记忆一定能替代触觉。

### 6.3 网络结构

策略频率先取20 Hz，现有仿真物理步长0.002秒；实物频率与延迟测量后统一确定执行节奏。

```text
部署观测 → 归一化 → MLP(256,128) → GRU(128) → 历史表示 h
                                                    ↓
教师特权物理量 → 32维编码 z ───────────────→ 动作头 → 26维动作
学生从历史估计32维 z_hat ─────────────────→ 同类动作头
```

教师特权量包括接触分布、负载、摩擦和延迟参数等；critic可读取完整物理状态。动作头分左右臂和左右手输出，PPO训练时探索，部署确定性执行。参考主要用于奖励，不向动作头提供“此时必须哪只手接管”的脚本标签。

先以教师轨迹初始化学生，再采用DAgger式数据聚合，逐步增加学生自主执行。教师在学生实际到达的状态和对应历史上重新给标签，不沿用名义演示动作。以动作蒸馏为主，可增加潜变量辅助损失；用连续序列、隐藏状态预热和真实episode边界训练记忆。

该结构是实施起点，不预先认定为论文创新。学生失败时，先查教师能力、特权差距、历史和接触可观测性，再考虑扩大网络。

## 7. 奖励与核心方法对比

| 目标 | 具体内容 |
| --- | --- |
| 任务跟踪 | 去程、停止、返回和连续指令的轮角／轮速误差 |
| 交互参考 | 连续段的主导／释放关系、大角度段的接管重抓顺序、接近区域和腕姿，允许局部调整 |
| 承载接管 | 减少回正负载下的失去支撑、轮角回退与超调 |
| 执行约束 | 关节余量、自碰撞、座舱碰撞、拨片受力、过大接触力和目标突变 |

分别记录各项数值和加权贡献，避免总奖励掩盖失败。四指、掌部、拇指接触在需要支撑的手上检查，不能要求两手全程全部接触，否则无法换握。不能把增大抓力本身作为收益。

仿真按物理步统计各手接触合力／力矩对轮轴的投影，结合外部负载与轮速变化分析承载。保持时包含外部负载的轮轴总合力矩接近零，双手仍可能承担非零负载；不能只按轮盘加速度或法向接触点数量判断承载。零位回正力矩可能为零，单手承载需在已确认非零负载的条件下验证。

关键比较是：**严格按时间跟踪交互参考，和允许接管片段内提前／延后、局部姿态变化。** 后者在同一参考的有序片段内设置局部匹配窗口，限制跳片和无期限停留；窗口、姿态容差和推进规则在正式比较前冻结。

两组使用相同参考、任务和动作边界。外部轮角指令按原时间推进，不能因参考调整而暂停任务时钟。奖励中的参考片段不作为部署的阶段控制器。

## 8. 仿真与实物怎样分阶段推进

| 阶段 | 仿真侧 | 实物侧同步工作 | 进入下一步的证据 |
| --- | --- | --- | --- |
| P0：仿真运动可行性 | 运动环境、低速转向、单手承载、静止及低速接管、连续范围与边界 | 暂无接口／数据；按用户要求后续R0单列 | 仿真可行性图、完整往返、接管片段、连续序列和失败边界 |
| R0：实物入口与标定 | 根据实测更新几何、负载、执行与时序 | 反馈、行程、负载、延迟和坐标标定 | 独立标定清单与真实基础技能；进入实物部署前完成 |
| P1：新交互参考 | 分别建立连续追踪、360°、540°行为参考，逐级验证可重放性 | 三类人类示范；基础技能；落实540°设备条件 | 分来源数据、参考覆盖范围、真实基础技能 |
| P2：教师学习 | ±180°双向连续追踪、首批接管技能和关键参考对比 | 根据实测修正模型，基础技能回归 | 含途中反向与跨零的结果、学习曲线和交接分析 |
| P3：历史学生 | 蒸馏、闭环评价和观测限制检查 | 冻结模型首次迁移，从小角度到接管、±180° | 教师学生差距、首次迁移全部尝试 |
| P4：大角度与统一 | 教师逐级完成±360°、±540°，再混合三类任务更新同一历史学生；适配后回归 | 在相应行程设备上完成360°、540°和统一长序列，按需补真实数据 | 三类任务分项结果、适配成本、完整视频与漂移 |
| P5：正式实验 | 冻结模型，独立任务、初态、负载和延迟测试 | 至少3个采集会话的正式评价 | 对照表、完整视频、失败案例及成本 |

P0未证明可行，不进入P2；关键假设没有收益时先诊断，不无限追加预算。540°的机械条件从R0开始解决，其训练可以晚于360°，但三类行为均属于最终目标。若540°仍未完成，应报告未完成部分，不能把整个方案标为已完成。

### 8.1 实物怎样验证和适配

先确认真实10点／2点抓握可以保持、左右单手承载和低速转动，再验证±180°内双向连续追踪、360°及540°的换握、保持与返回，最后连接成长序列。仿真接管窗口仅为初始参考，实物重新确认；540°使用匹配其行程的设备版本。

首次迁移前冻结学生，保留全部尝试。失败先查坐标、单位、同步和动作映射；摩擦、回正负载或驱动差异明显时修正仿真与随机化；仍缺真实接触协调时采集遥操作／人工纠正数据，用BC或受约束微调适配。不默认在实物从零探索RL。

自主失败日志用于诊断，含可靠专家标签的轨迹才直接用于BC。记录人工介入、外部扶持和中断，正式任务中人工接管计失败。首次迁移与适配后结果分开，用新会话留出任务复评。

实物需要同步轮角和回正负载标定。报告逐手承载力矩需要相应测量或经验证估计；缺少测量时，只报告轮角、已标定负载和可见接触变化，不拿仿真曲线替代实物证据。

## 9. 论文实验怎样安排

### 9.1 比较对象

| 对照 | 回答的问题 |
| --- | --- |
| 新场景显式控制 | 工程可行性与学习收益 |
| 无交互参考RL | 参考是否降低探索难度／提高完成率 |
| 固定时间参考RL | 允许调整参考是否必要 |
| 可调整参考RL | 候选主方法 |
| 教师、历史学生、无记忆学生 | 特权差距、记忆与部署能力 |
| ACT、Diffusion Policy | 同机器人专家数据条件下动作序列模仿的边界 |

先做工程试训，再开展正式比较。正式RL至少3个训练种子；根据P0吞吐，在比较前冻结相同交互预算、评价次数和检查点。分别报告示范采集、专家生成、训练和真实适配成本。

模仿对照使用相同数据划分、部署观测、物理动作边界和评价器，明确动作序列长度、重规划频率和推理成本，不把不同数据成本包装成完全同预算。完整轨迹／采集会话划分训练、开发和最终留出，调过参数的案例只算回归。

### 9.2 完整成功与失败指标

- 任务成功率、运动RMSE、全程峰值、停止误差、回正误差和完成时间。
- 交接时回退、超调、承载中断、打滑／失握事件和接管次数。
- 与人类参考的主导／释放关系、交接顺序、重抓区域和腕部运动相似度，区分时间适配与行为顺序改变。
- 关节余量、腕姿变化、非法碰撞、拨片／轮辐受力、接触力和动作变化率。
- 连续往返后的轮角、控制目标与抓握漂移，以及实物介入。

名义研究目标沿用运动RMSE≤1°、每次停止末段3秒峰值误差≤1°，保持时长3秒／10秒，完整通过率目标95%以上。它们不是已有能力；P0采用独立的较宽工程门槛。正式门槛在独立评价前冻结。

实物噪声或分辨率不支持1°判断时，先改善测量或在正式试验前另定门槛。未完成、人工接管、非法碰撞和越界分别计失败，不用平均误差抵消；成功率同时报告样本数和不确定性。

### 9.3 泛化先围绕2号展开

先测试10点／2点附近抓点、标定误差、摩擦、回正负载、延迟、速度和保持时长变化，范围由可行性与实测确定，冻结后评价。留出完整终点／指令序列，左右方向分别报告。

正式结果至少按三类分表：±180°双向连续追踪、360°操作、540°操作；另报告统一长序列。连续追踪必须包含同侧反向和跨零，不允许全部由独立零位往返替代。分别列出仿真与实物、左右方向、初始迁移与适配后结果。

9点／3点作为后期更明显的初态变化：分别报告2号训练策略直接测试，以及补充该初态训练后的结果，不能将训练过的初态写成零样本泛化。360°／540°模板通过不代表任意多圈指令泛化，长序列单独测试。
