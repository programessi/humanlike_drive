# R0：实物入口与标定（后续单列）

2026-11-07，用户确认这台电脑暂无机器人／方向盘反馈接口或标定数据，本轮先完成仿真P0。R0尚未开展，不计入本轮仿真验收，也不将合成负载当成实测负载。

当前按[三层研究计划v4.1](RESEARCH_PLAN.md)推进。场景保留，旧P0仅作历史参考，新实验尚未执行。当前主线为9点／3点自然初态、掌心径向预紧产生切向摩擦主驱、手指顺应维持；R0核对掌面实际接触区域、掌轮摩擦及滑移、轻握输出和力反馈可用性；没有掌部触觉时，不将仿真接触真值作为部署输入。

实物分别对应三层：先在R0后验证物理操作，再测试合理适配的已有方法，存在明确不足时再检验新方法。优先检查自然腕姿下两手上半圆操作和0—180°动态往返；需要交接时检查抓上、承载及继续操纵，再有条件扩展重复接力。不固定每180°切换，360°／540°不阻塞当前仿真范围。不预先要求采用B0或教师学生。

## 需要落实的内容

| 项目 | 要得到的记录 |
| --- | --- |
| 设备与行程 | 机器人、Inspire和方向盘型号，轮盘居中零位、正方向、连续累计角和机械限位。当前G29居中±450°不足以完成最终±540°任务，扩展该任务前需相应行程设备，不阻塞当前0—180° |
| 反馈与动作 | 臂关节和手驱动可读字段、单位、频率；26个独立驱动的映射；手指原始mimic关系；区分实测值与命令 |
| 轮轴负载 | 多角度、多速度、左右方向的回正、摩擦、阻尼和回差；区分空载曲线与手接触后的响应 |
| 时序 | 机器人和轮角反馈时间戳、同步、滤波、延迟及丢帧；验证20 Hz策略与底层目标插值能否实际执行 |
| 坐标与几何 | 机器人到轮轴的标定、轴倾角、轮圈尺寸、碰撞近似与安装误差 |
| 执行能力 | 有限输出、关节范围、目标速度、预紧上限、实际重力补偿能力及接触力边界 |
| 掌部接触与感知 | 实际掌面可接触区域、掌轮摩擦／滑移、轻握与预紧边界，确认有无可读触觉／力反馈；标明只能估计的字段 |
| 基础实物片段 | 从9点／3点掌面贴合、单手承载、小角度到上半圆／0—180°往返，按需加入静止／运动交接；重复接力后续扩展；不要求每指一直接触；逐级提高速度和实测负载 |
| 数据归档 | 原始记录放在data/calibration/和data/raw/robot/；manifest记录设备、会话、单位、版本和哈希 |

所有行目前均为待完成。首次迁移和适配后结果分别统计；后续先在真实设备确认基础能力，再验证±180°连续任务、360°与540°操作。仿真接触力矩不充当实物逐手力矩测量。

当前仿真入口见[掌部主导P0协议](../experiments/PALM_PRIMARY_P0.md)，历史结果见[旧P0报告](../../results/p0_complete_20261107/README.md)，总路线见[研究计划](RESEARCH_PLAN.md)。
