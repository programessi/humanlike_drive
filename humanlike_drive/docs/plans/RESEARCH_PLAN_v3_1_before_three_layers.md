# Humanlike Drive详细研究计划：掌部接触与双手接力

版本：v3.1，2026-11-07。当前状态：详细方案已制定，新路线的仿真P0、策略训练和实物实验尚未开展。

**研究主线：用掌部稳定传递转向力矩，用手指辅助维持接触；让一个统一策略根据目标、当前双手状态和历史，完成局部双向操纵、承载接管和重复接力。**

**当前执行优先级：先建立[B0基础线路](BASELINE_IMPLEMENTATION_V1.md)。** 为降低起步复杂度，B0采用非循环特权MLP教师、短程BC初始化和PPO，再训练GRU历史学生；不加入角色预测、转移可行性、承载余量或独立协调器。本计划第6—9节的更复杂结构是后续候选与对照，不作为当前基线的前置要求。具体网络与实施顺序以B0文档为准，物理约束、任务目标和实物要求继续按本计划。

此前成功的左右90°案例已[独立备份](../../results/archive/20261107_pre_palm_primary/README.md)，仅作历史参考，不作为当前路线的初态、专家数据或通过证据。[v3.0](RESEARCH_PLAN_v3_0_before_relay.md)与[v2.3](RESEARCH_PLAN_v2_3_before_palm_primary.md)保留供追溯。本版取代按“180°基础、360°／540°各自特殊策略”组织能力的思路。

## 1. 先明确我们现在的判断

### 1.1 机械手适合怎样接触

Inspire手指无法完整复现人手侧摆，因此不强求深包握或每根手指持续接触。首选候选是：掌面贴合轮圈，四指适度弯曲限制相对滑移和脱离，拇指在可达时提供侧向支撑。

压紧产生法向力，沿轮圈切线的接触力产生转向力矩。理想圆环上，朝轮心的径向压力本身不直接产生绕轴转矩。掌部主导必须由实际轮轴力矩贡献、滑移和负载响应证明，不能只看掌压大小或视频外观。

### 1.2 人类式接力提供了什么规律

理想化的单向操作可以写成：

```text
手A操纵约一段 → 手B接管并操纵 → 手A再次接管并操纵 → …
             360°约两段，540°约三段，每段名义跨度约180°
```

这是用于缩小探索空间的行为先验，尚不是机器人的已验证事实。更准确的表述是“从上部合适区域接近，在有限舒适范围内操纵，适时交替接管”。不要求手全程只在上半圆，不固定每180°换手，不默认左右完全对称。

同一抓点转180°会走过一个半圆；是否恰好位于上半圆取决于起点和方向。10点／2点只作为新候选起点，允许根据掌部贴合、腕姿和拨片间隙调整。

### 1.3 180°、360°、540°怎样重新定位

它们是任务范围和课程，不是三套策略。基础能力应定义为：**在当前接触状态下，能够转动、停止、反向，并在必要时通过另一只手接管继续完成任务。**

360°和540°复用这些能力，但仍需训练多次接管、漂移和返回。固定轴负载可能随累计轮角变化，轮辐／拨片影响局部几何，接管后抓点也可能变化，所以大角度不是完全相同动作的机械重复。

## 2. 论文问题与需要检验的假设

论文准备回答：**在手指运动能力受限的坐姿人形机器人上，能否以掌部主导的接触方式，结合人类双手交互先验，用一个策略完成长时序双向转向和大角度接力？**

| 假设 | 怎样验证 | 什么情况说明没有成立 |
| --- | --- | --- |
| H1：掌部可成为主要传力区域，手指主要辅助稳定 | 分部位轴向力矩、受载滑移、轻握程度对照、不同负载／摩擦 | 主要依靠指端卡住、非轮圈接触或极高预紧才能转动 |
| H2：局部操纵与接管可重复组合 | 接管后继续操作、第二／第三次接管、不同接管起点 | 单次接管成功，但新手无法继续操纵或多次接力迅速失稳 |
| H3：交互参考和衔接训练降低长序列学习难度 | 有／无交互参考，有／无接管后继续操作的训练 | 同预算下没有收益，或改善仅来自更多数据／额外传感 |
| H4：部署观测与历史足以保留关键能力 | 教师学生差距、历史编码对照、真实迁移 | 学生始终无法识别接触丢失，必须增加实际反馈或改变接口 |

掌部接触、共享网络或使用GRU都不预先宣称为创新。潜在贡献在于：适合当前硬件的传力机制、面向后续可操作性的接管学习，以及统一长序列与实物证据。贡献表述随实验结果收敛。

## 3. 任务与坐标：把整个任务和当前接触分开

### 3.1 全局任务

轮角使用连续累计值，任务约定右正左负，并标定与MuJoCo／编码器的符号映射。保留三项不同信息：

- `theta_goal`：当前任务段的最终目标，如360°。
- `theta_ref(t)`、`omega_ref(t)`：当前时刻的平滑参考角与轮速。
- `theta(t)`、`omega(t)`：实际累计轮角与轮速。

输入剩余角度及跟踪误差，不用取模后的轮角代替累计轮角。可额外输入sin／cos帮助表示周期几何，但它们不能区分0°、360°和540°。

目标处保持与回正均由指令定义。回正先研究受控返回，不依赖撒手后轮盘自动弹回。整段不因换手暂停任务时钟，不重置抓握目标、网络记忆或轮角。

### 3.2 局部接触状态

对每只手，表达腕／掌相对轮轴的位置、朝向、运动，以及关节余量和已下发目标。坐标系固定在轮轴安装基座上，轮圈材料运动由轮角另行描述，避免把静止基座系与随轮盘旋转的坐标系混在一起。

任务需要知道“当前谁在操纵、谁准备接管”，但学生不能直接读取真实接触、真实主导手或脚本阶段。接触角色由历史估计；如使用抓握锚点／局部进度，也必须说明它们如何由部署可用反馈估计，以及失接触时如何更新。

首版优先直接输入经标定的腕轮关系与运动历史，不引入依赖完美接触检测的隐藏重置器。

### 3.3 四类必须完成的任务

| 类别 | 内容 |
| --- | --- |
| 连续追踪 | ±180°内平滑同侧增减、途中反向、跨零、停留和继续运动 |
| 360°操作 | 左右方向完整转动、必要接管、终点保持与受控回正 |
| 540°操作 | 左右方向更长接力、保持和回正 |
| 混合长序列 | 同一策略连续接受不同目标，检查累计漂移和历史依赖 |

示例连续指令为平滑的 `0→+70→+25→−40→+110→0`，不是瞬时角度跳变。360°、540°的去程和返程都独立检查；达到终点后返回失败，完整任务仍失败。

G29居中行程为±450°，不支持居中向任一方向540°。540°需长行程轮轴／设备和单独版本模型；不能只改原G29止挡就宣称验证原装设备。原G29用于其真实范围内的阶段验证，最终540°目标保留。

## 4. P0：先建立真实可用的接触与接管

详细物理条件、传力公式及工程门槛沿用并补充[掌部主导P0协议](../experiments/PALM_PRIMARY_P0.md)。用户已确认暂无实物接口和标定数据，因此当前仿真阶段不等待硬件；所有合成负载明确标注。

| 子阶段 | 工作 | 产物与进入下一步的条件 |
| --- | --- | --- |
| P0-A | 校核掌面碰撞；少量自然腕姿候选；双手及左右单手10秒保持；双方向非零负载 | 掌／指转矩与负载平衡、滑移、自然腕姿、有限输出；确认掌部主导的可用窗口 |
| P0-B | ±15°、±30°、±60°完整往返，同侧反向与跨零；再决定是否扩到90° | 新机制下完整轨迹与视频，冻结接触、滑移和执行边界 |
| P0-C | 摩擦／负载／初态扰动，轻握对照，停稳与运动接管，接管后继续操纵 | 双向接管窗口、后续可操作性及重复接力的工程入口 |

保留坐姿、驾驶室、大屏、倾斜轮轴、拨片、轮辐和自碰撞。H1-2原限位、Inspire六驱动和mimic不变。少量整手候选用于寻找功能合理的位置，不逐指精修，不用提高摩擦或虚构掌部凸起制造成功。

**在原P0-C上新增衔接检查：**新手承载、旧手退离后，新手应继续同向转动一段，再停止、反向并保持。先取继续30°、反向15°作为候选；若几何范围不足，在开跑前选定并记录另一跨度。期间不重置状态。仅“新手抓上并静止10秒”不足以证明能够接力。

P0以显式控制寻找可行片段，允许使用仿真接触反馈。它是参考生成与工程基线，不代表最终部署策略具备相同传感器。

## 5. P1：构建可衔接的参考，而不是收集三个终点动作

### 5.1 人类参考记录什么

重点记录轮角变化、双腕相对轮盘轨迹、手的接近／释放区域、接管先后和停顿。人手指姿态用于定性理解，不逐关节映射到机械手。

先利用少量视频明确事件与标注规范，具备条件后采集同步轮角和腕部运动。约20段只作为首批覆盖检查，不视为足够训练或完成拟人性评价。人类采集不作为当前P0的前置条件；没有可用人类数据时，先做明确标为合成的机器人参考，不宣称已验证人类行为模仿。

人类示范、仿真参考和真实机器人示范分别归档。接触遮挡时标未知，视频可见接触不作为真实承载力矩标签。

### 5.2 参考单元怎样组织

| 单元 | 必须覆盖的变化 |
| --- | --- |
| 局部操纵 | 左右手、两个方向、不同起始抓点、保持、反向、小幅修正 |
| 承载接管 | 左到右／右到左、停稳／持续运动、不同负载与接近窗口 |
| 接管后继续操作 | 新手继续转动、停止、反向，旧手完成回到准备区 |
| 多次接力 | 第二／第三次接管、不同剩余目标、返回与回正 |

保存单元前后的真实机器人状态和上下文，尤其是另一手是否回到可再次接管的位置。大角度轨迹必须连续物理执行，不能把几个成功片段剪接成新的成功证据。

### 5.3 衔接怎样进入数据和训练

将第一次接管后的状态，作为后续操纵的实际起点；将第二次接管的失败反馈到前一次抓点与退手路线。只修复后一段，可能无法解决前一段留下的不合适姿态。

记录两个不同标签：“已经建立接触”和“后续操作成功”。后者通过规定后续任务的实际滚动获得，不能用接触阈值代替。若训练转移可行性预测器，标签需包括后续任务、方向和负载条件。

按完整轨迹／会话划分训练、开发与留出。来自同一长序列的相邻片段不能分到两侧。

## 6. 主策略A：统一历史网络，共享协调状态

这是首个实现和主基线。选择理由是能力反复使用、动作维度仍可管理，且可以避免初期同时训练切换器与多个子策略；不预设它一定优于层级结构。

### 6.1 输入和网络

```text
任务：目标、参考、实际轮角／轮速、误差 → 任务编码器64维 ─┐
左侧：臂手反馈、腕轮关系                 → 左编码器64维 ──┤
右侧：臂手反馈、腕轮关系                 → 右编码器64维 ──┤
上一动作与已下发目标                    → 历史动作编码64维 ┘
                                                      ↓
                                              MLP(256,128)
                                                      ↓
                                                 GRU(128)
                                                      ↓ h
教师：特权物理量 → MLP → z(32) ────────────────────────┐
学生：部署历史 → 估计z_hat(32) ────────────────────────┤
                                                      ↓
                                                融合动作层
                          ┌────────────┬────────────┬───────────┐
                       左臂7维       右臂7维       左手6维     右手6维
```

各分支先独立编码，再共享同一个历史表示。四个输出头是一个策略的一次联合动作，不是四个独立训练、各自决定接管的策略。左右编码器首版参数独立；共享权重和镜像增强是后续对照，不能假设手型、负载与座舱严格对称。

网络尺寸是实施起点，不是论文结论。第一轮固定其它部分，仅比较GRU128与有限历史时间卷积；时间卷积首个窗口可取30步，即20 Hz下1.5秒。记忆状态与窗口长度的成本分别报告，不声称两者具有完全相同的历史容量。

### 6.2 观测与教师特权的边界

| 部署候选观测 | 限制 |
| --- | --- |
| 臂关节位置／速度 | 真实反馈，加入滤波、噪声和延迟 |
| 手驱动反馈 | 以硬件实际字段为准，不假设每个mimic指节均有直接编码器 |
| 腕／掌相对轮轴位姿和运动 | 正运动学与标定获得，不读无噪声仿真真值 |
| 累计轮角／轮速、任务指令 | 编码器与实际在线提供的参考；预览首版候选0.5秒，各方法相同 |
| 上一动作、目标和执行历史 | 记录实际下发命令，区分命令与实测 |

教师额外读取掌／指接触、摩擦、负载、执行器参数等，critic可读取完整状态。学生只能估计潜变量，不能获得真实接触角色、参考片段编号或预设接管时刻。教师能力和学生能力分别评价。

可增加角色辅助头，从部署历史表示h预测“左手操纵、右手操纵、左到右交接、右到左交接、双手保持”，不直接从特权z读取答案。这些是粗粒度交互状态，不是人类行为的完整分类。初始角色标签来自参考和实际受力核对，不确定样本屏蔽；它只用于辅助学习和诊断，不硬切动作或强制开手。

### 6.3 动作怎样执行

输出26维归一化目标变化率，映射到14个臂关节和12个手驱动，经限速、限位、目标相对实测偏差上限和有限PD输出执行。策略先20 Hz、物理500 Hz，底层插值。

手指不增加侧摆自由度，也不要求策略逐指追求接触点数。通过轻握参考和过大预紧／动作惩罚减少无效手指运动，但保留原驱动的必要调整能力。

P0掌部接触反馈器不自动成为学生执行层。如果后续采用结构化腕部／轻握动作或实际可部署的贴合控制器，必须先独立验证、另记接口，再让所有方法在同一边界比较，不能暗中读取仿真接触真值。

## 7. 对照策略B：显式协调意图，共享局部控制

用于回答：长序列是否需要显式表示“谁操纵、何时交接”。先完成A的基础版本，再构建B，避免同时开发多套复杂框架。

```text
相同部署观测与历史 → 学习到的协调器 → 当前角色／接管意图
                                            ↓
相同观测与历史 ─────────────────────→ 共享局部控制器 → 26维动作
```

协调器首版采用相同20 Hz更新，不预先增加第二套时钟。意图用类别概率或嵌入输入局部控制器；若做离散切换，再单列滞回、最短持续时间等规则，不把它们藏在实现中。局部控制器覆盖两手与两个方向，不另训“360°网络”和“540°网络”。

B先用与A相同的参考标签初始化角色预测，再联合优化协调器和连续控制器。首版采用可微的软意图，结合PPO目标和逐步减弱的角色辅助损失，不把参考类别作为推理输入。这个版本检验显式角色表示是否有用；只有其证据支持后才考虑离散选项与技能切换，不一开始同时增加两套离散／连续探索。

转移可行性可作为辅助预测，学习“当前交接之后是否还能完成指定的后续操作”；它不能靠角度阈值或瞬时接触点数替代，也不能在部署时读取真实接触。为避免把层级结构与额外监督混淆，A也获得等量角色／可行性辅助标签，B的额外训练成本单列。

B是一个统一的部署控制系统，但含显式协调模块，与A的单个直接动作网络有区别。如果B更好，按证据选择B；如再蒸馏为单网络，必须重新评价，不能假设蒸馏无损。两者都满足不按目标角度切换多套策略的要求。

## 8. P2：先训练教师，再检验重复接力

### 8.1 课程顺序

| 顺序 | 训练任务 | 通过后才增加的难度 |
| --- | --- | --- |
| C0 | 掌部贴合、保持、小角度，左右手分别非零负载承载 | 初态／摩擦微扰 |
| C1 | 单手双向操纵、停止、途中反向，另一手释放和返回准备区 | 更大局部工作范围，不要求恰好180° |
| C2 | 一次停稳接管，再低速运动接管 | 多接管起点和两方向 |
| C3 | 接管后继续同向转动、停止和反向，再完成第二次接管 | 连续接力和不同剩余目标 |
| C4 | ±180°连续追踪，混合同侧增减、跨零和停留 | 目标在线变化及完整回正 |
| C5 | 360°去程、保持、返回，混入前述短任务防遗忘 | 冻结模型做更长任务探查 |
| C6 | 支持行程的模型上训练540°及混合长序列 | 更长时长和扰动 |

训练允许从物理合法中间状态开始；状态来源须记录，控制目标和GRU状态要预热，不能随意拼接隐藏状态。最终从规定初态完整执行，接管时不reset。

固定360°训练后的策略，可在同一长行程模型上测试未训练540°，作为组合外推探查；若失败，报告失败并进入C6。训练过540°后的结果不能再称为零样本接力泛化。

### 8.2 奖励和参考

候选总目标包括轮角／轮速跟踪、交互参考、接管连续性、滑移、过大预紧及执行约束。奖励实现前逐项定义单位、归一化、权重和终止事件，不直接沿用旧总奖励。

- 跟踪：外部参考按原时间推进；接管不能通过停任务时钟降低误差。
- 掌部接触：仅在需支撑的手上约束贴合，释放手没有接触要求；不奖励压力无限增大。
- 行为参考：上部合适接近、主导／释放关系、先承载后释放及自然腕姿；不强制每指接触或每180°切换。
- 衔接：训练接管后继续操作，必要时增加经实际滚动验证的可行性辅助损失；不靠“换手次数越多越好”的奖励。
- 参考适配：允许有限的局部时间／姿态调整，但保留交互顺序，限制跳段和无期限停留。匹配窗口在正式对比前冻结，参考阶段不作为学生输入。

自然腕姿从可行范围与人类参考共同确定；不能只以不越关节限位判定拟人。硬物理失败在评价中独立计数，不用总奖励或平均误差抵消。

### 8.3 首批诊断的停止规则

若局部操纵本身失败，先查接触、坐标、动作尺度和有限执行，不扩大网络。若单次接管成功但连续失败，先查接管后的可操作状态和释放手返回路线。若教师成功、学生失败，先查特权差距和反馈可观测性。

不为一个开发序列无限调参。P0测量吞吐后，P2试训开始前冻结每阶段交互预算、检查点和最大调参次数；正式比较另立预算，包含预训练及辅助标签生成成本。当前缺少新环境吞吐，不虚填总GPU小时或完成日期。

## 9. P3：历史学生和部署约束

教师在冻结的开发任务上具备完整能力后，再蒸馏。先用教师轨迹初始化，随后逐步增加学生自主执行，采用DAgger式数据聚合。

教师必须在学生实际访问的状态及相应历史上给动作标签；重建／预热教师记忆，不能沿用教师名义轨迹中的旧隐藏状态。学生以动作拟合为主，可加潜变量、角色或接触状态辅助损失，标签仅用于训练。

使用连续序列、episode边界和记忆预热训练，分别评价教师和学生完整任务。P4增加540°后，教师与学生都要更新，保留之前连续追踪回归。

若本体反馈不能可靠识别滑脱，优先比较有限真实触觉、力估计或真实纠正数据的收益，不预设GRU一定能补齐所有缺失信息。

## 10. R0与实物实验：始终属于论文的一部分

当前暂无接口／标定，R0后续单列，不阻塞仿真P0。实物部署前必须完成[实物入口与标定](R0_HARDWARE_CALIBRATION.md)。

| 实物步骤 | 工作与证据 |
| --- | --- |
| R0标定 | 行程、轴位姿、掌面几何、负载／摩擦、26驱动映射、反馈字段、延迟与有限输出；落实540°设备 |
| R1基础接触 | 掌部保持、左右单手非零负载、±15°／±30°低速；核查仿真机制是否对应真实接触 |
| R2交接 | 停稳接管、低速运动接管、接管后继续操纵和反向 |
| R3完整任务 | ±180°连续、360°、540°及受控回正，在匹配行程设备上完成 |
| R4统一与正式评价 | 混合长序列、多采集会话、漂移、失握和恢复；完整视频及全部失败 |

冻结学生首次迁移，记录全部尝试；先检查单位、坐标、时序和动作映射，再修正负载、摩擦与执行模型。必要时采集遥操作／人工纠正的真实专家数据做BC或受约束微调，不默认实物从零探索RL。

首次迁移和适配后分别统计，保留适配数据与成本，使用新会话／新序列复评。正式任务中人工扶持、接管和中断分别记录并判任务失败。

无真实接触力测量时，不报告未经验证的逐手承载力矩；可报告轮角、标定负载和可见接触／滑移。仿真力矩曲线不能代替实物证据。

## 11. P5：对照、验收和论文图表

### 11.1 分批安排对照

| 优先级 | 比较 | 回答的问题 |
| --- | --- | --- |
| 首批 | 新P0显式控制、统一策略A | 工程入口与学习策略是否真的有效 |
| 首批 | A与B，使用相同任务、执行边界和可用标签 | 是否需要显式协调意图 |
| 核心 | 有／无交互参考；有／无接管后继续操作训练 | 行为先验与衔接设计是否有贡献 |
| 核心 | 教师／学生；GRU／时间卷积历史 | 迁移损失、历史表示与观测限制 |
| 后续 | 严格时间参考／局部适配 | 对齐自由度是否改善接管 |
| 后续 | ACT、Diffusion Policy同数据模仿 | 长序列与分布偏移下的边界 |
| 机制 | 同一新场景下不同轻握程度／指端主导对照 | 掌部主导和手指辅助是否成立 |

不同结构若使用不同数据或额外训练，单列成本。正式RL至少3个种子，提前固定交互预算、评价任务、检查点选择和调参历史。先做必要核心比较，再根据发现增加消融，不同时展开全部组合。

### 11.2 完整成功与行为评价

报告任务成功率及样本数／不确定性、运动RMSE与全程峰值、各次停止／回正误差、完成时间。另报滑移、失握、交接回退与承载中断、无效换手、实际接触力／转矩、输出饱和、关节余量和碰撞。

连续长序列额外报告：第几次接管失败、接管后继续操作成功率、累计漂移、是否出现重复接近或犹豫。与人类参考比较分工、顺序、接近区域和腕轨迹，允许时间适配，不能只看终点相同就称为拟人。

| 层级 | 门槛及适用范围 |
| --- | --- |
| 新P0 | 运动RMSE≤2°、停止末1秒峰值≤2°，有效承载与碰撞等按新协议；不是成功率结论 |
| 正式仿真／实物 | 初始目标为运动RMSE≤1°、各停止末3秒峰值≤1°，保持3秒／10秒、完整成功率目标≥95%；均不是已有结果 |
| 测量与冻结 | 实物噪声不支持目标精度时先改测量，或在正式评价前另定合理门槛；不能看留出结果后降低 |

三类任务分别列仿真与实物、左右方向、教师学生、首次迁移与适配后结果；混合序列另列。未完成、碰撞、越界、人工接管均为失败，误差小不能抵消。

### 11.3 计划中的关键图表

1. 接触机制图：掌面与各指接触点、法向／切向力、轮轴力矩和滑移。
2. 接力时间线：轮角、双手角色、实际承载转移、释放手回到准备区。
3. 局部工作区与接管窗口：标明起始抓点、负载、方向，不用单一累计轮角代表全部可达性。
4. 接管后继续操作及第二／第三次接力的成功率，比较衔接训练前后。
5. 统一长序列的完整轨迹、误差、漂移和失败，仿真与实物分别呈现。
6. 学习／数据成本、A与B、教师学生及核心消融表。

## 12. 论文依据及我们额外提出的部分

| 工作 | 已支持的思想 | 本项目怎样用、不能外推什么 |
| --- | --- | --- |
| [PatternDex，2026预印本](https://arxiv.org/abs/2610.04765)，[本地全文](../../../references/02_双臂双手协同/PatternDex/paper.pdf) | 物体—腕部交互模式，适配机器人形态的腕／接触指导 | 模仿交互而非复制手指；论文使用参考指导和残差，不能据此保证自主重复接管 |
| [Sequential Dexterity，2023](https://arxiv.org/abs/2309.00987) | 转移可行性、子策略衔接与前后共同调整 | 训练前一段为后一段留下可用状态；该工作采用多子策略，不能作为单GRU优越性的依据 |
| [AsymDex](https://arxiv.org/abs/2411.13020)，[本地全文](../../../references/02_双臂双手协同/AsymDex/paper.pdf) | 主辅角色、相对坐标 | 我们需要角色交替且两手作用于同一刚体，不能直接照搬固定主辅动作空间 |
| [HORA，CoRL 2022](https://arxiv.org/abs/2210.04887)，[本地全文](../../../references/01_旋转与换握/HORA/paper.pdf) | 旋转中的接触循环、特权隐变量与本体历史适配 | 支持历史与适配，原历史模块为时间卷积，不证明GRU最佳；任务为单手指内旋转 |
| [DexScrew](https://arxiv.org/abs/2512.02011)，[本地全文](../../../references/01_旋转与换握/DexScrew/paper.pdf) | 简化固定轴旋转、教师学生及技能辅助真实数据适配 | 借鉴训练分工；完整实物路线有真实示范／触觉BC，不能保证纯仿真迁移 |
| [DeepMimic，SIGGRAPH 2018](https://xbpeng.github.io/projects/DeepMimic/index.html) | 参考模仿与任务目标共同优化、多技能学习 | 指导行为风格与任务兼顾，不直接解决方向盘接触承载 |
| [DAgger](https://proceedings.mlr.press/v15/ross11a.html) | 在学生访问状态聚合专家标签 | 用于闭环学生训练，不沿用名义轨迹动作 |
| [ACT](https://tonyzhaozh.github.io/aloha/)、[Diffusion Policy](https://diffusion-policy.cs.columbia.edu/) | 动作序列模仿 | 作为同新专家数据和部署边界下的对照，不是当前主线算法 |

共享编码器、GRU128、四个输出头、角色辅助头，以及掌部主导判据，均是面向本项目的待验证设计，不是上述文章已经证明的标准结构。180°重复分解也不直接构成算法创新。
