# 层1工程系统的选择与证据边界

本轮按用户要求，完成仿真中的物理可行与工程检查，不开展学习策略训练。当前结果与完整判定见[验收报告](../../results/physical_feasibility/l1_v1/README.md)。

1. **保持场景，独立建立接触版本。** 保留坐姿驾驶室、G29视觉和原装配结构。发现原掌部整体凸包填平CAD凹处，不能再用其成功结果证明真实掌面传力。新增按原三角面裁切的掌部碰撞体；旧场景不覆盖，运行生成单独XML，并抽样核对实际受载接触到视觉CAD的距离。
2. **采用整体轻握和自然腕姿。** 从9点／3点建立接触，调整整手轴向位置和统一轻握程度，避免拇指挡住掌面及小指碰底座；不逐指精修，不增加侧摆或假接触垫。腕姿门槛是工程约束，不等于经人类数据验证的拟人性指标。
3. **用空间窗口驱动累计轮角。** 每手使用自己一侧的短上半圆窗口，按需停稳接力。轮角可以累积超过手的空间行程，换手时不重置轮角或控制状态。当前不是每180°固定换手，也不是180／360／540三个独立动作脚本。
4. **用真实受力判断交接。** 新手建立掌面接触、承担可测反负载转矩后，旧手才退出；新手需要独立保持10秒并继续运动。固定时间v2在负80°处因接触稳定时间不足而停；v3允许在原稳定状态最多额外等5秒，负向实际多等0.2秒后完成，不放宽接触／力矩条件。计划与实际等待均保存。
5. **区分数值接触与控制问题。** 同一状态的固定命令试验显示，摩擦锥和阻抗比明显影响慢滑移。采用椭圆锥、阻抗比10并记录求解设置，但5°/s完整轨迹仍有短时压力尖峰，不能记为通过。先冻结1°/s再进行新一批验收，保留8 N瞬时掌力门槛；不是提高门槛让旧结果通过。
6. **不把基线说成最终成果。** 它是使用仿真特权接触的非学习工程控制器。通过的范围支持第二层同条件学习比较；运行效率、对未见目标的自主重规划、无触觉部署和实物迁移均需后续验证。手指轻握保持了合法姿态，是否改善稳定性由实际消融决定。

7. **扰动必须从合法初态出发。** 旧直接在已接触状态移动qpos的探针会产生初始穿透／冲击，保留但排除正式扰动统计。正式15例使用各手±1 mm范围内径向／切向目标配准偏差，经有限电机执行；摩擦0.7、负载0.12 N·m及联合条件各5种子。这是目标标定误差探测，不是随机物理初态或统计可靠性证明。

掌压、轮角、执行器输出、接触力矩、滑移和碰撞均按500 Hz保存；几何摆姿、日志可视化与真正命令重执行分开标注。正式实物入口仍为[R0](../plans/R0_HARDWARE_CALIBRATION.md)。
