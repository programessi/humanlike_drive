# 配置

参考Diffusion Policy采用按职责组合配置的方式；本轮只预留分组，暂不放入未经讨论确认的默认参数。

| 分组 | 准备存放 |
| --- | --- |
| task | 角度范围、时间参考、初始状态、奖励、终止与接口版本 |
| policy | 策略类型、历史记忆、动作表示及动作序列长度 |
| model | 编码器、循环/Transformer模块、网络宽度与输出头 |
| dataset | 数据版本、来源、划分、采样、归一化与增强 |
| workspace | RL、BC、教师学生/蒸馏的训练参数、恢复与日志 |
| env_runner | 开发/回归/独立评估案例、冻结种子与指标门槛 |
| controller | 腕手动作尺度、IK/QP、限速与输出边界 |
| real_world | 硬件接口、设备频率、同步、反馈和标定引用 |

后续训练入口读取顶层配置并组合上述分组，完整解析结果随每次运行保存在outputs。当前尚无可执行配置。
